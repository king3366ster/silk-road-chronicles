## 一、宗教制度转换概述

西域五十国共有**6种宗教**（佛教R1、儒教R2、拜火教R3、多神教R4、圣女教R5、萨满教R6）。宗教制度转换是国家改变官方信仰的系统性过程，分为**主动转型**和**强制同化转型**两种。

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **主动转型** | 玩家主动选择改宗，需满足对应宗教转型事件的条件。详情见[08-宗教.md §4](08-宗教.md) |
| **强制同化转型** | 征服敌国后，宗教制度与政治制度、军事制度**同步强制同化**，不可分割 |
| **制度联动** | 宗教转型同时影响政治制度兼容性、外交关系、人口满意度 |
| **可逆性** | 除全女国"圣水纯化"锁定R5外，其他宗教转型均可逆 |

### 1.2 强制同化中宗教同步规则

> 此规则与[01-世界观.md §6.5.1](01-世界观.md)保持一致。

| 同化维度 | 强制同化 | 可选双轨 | 说明 |
|----------|:--------:|:--------:|------|
| 政治制度 | ✅ 强制同步 | ❌ 不可双轨 | 被征服国强制使用征服国政治制度 |
| 军事制度 | ✅ 强制同步 | ❌ 不可双轨 | 被征服国强制使用征服国军事制度 |
| **宗教制度** | ✅ **强制同步** | ❌ **不可双轨** | **被征服国强制改宗征服国宗教** |
| 经济制度 | ❌ 可选 | ✅ 可双轨 | 可根据城邦特性保留原经济制度或统一 |

> **强制同化流程**：征服国选择强制同化 → 自身先调整（可选） → 对被征服国同步推行政治+军事+宗教同化 → 经济制度可选双轨

## 二、宗教转换基本规则

### 2.1 转换基本规则

| 规则项 | 说明 |
|--------|------|
| **转换范围** | 可在6种宗教之间转换，需考虑宗教兼容性与制度匹配 |
| **转换前提** | 稳定度≥60，且满足对应宗教转型事件的触发条件 |
| **冷却时间** | 转换后需间隔24回合（约8个月）方可再次转换 |
| **转换消耗** | 500~3000金（视改宗跨度大小，同兼容等级消耗低，低兼容消耗高） |
| **转换耗时** | 3~6个月过渡期（过渡期内稳定度-10/月，原宗教信众不满） |
| **稳定度影响** | 转换后稳定度-15~-25（随时间恢复），与新旧宗教兼容度负相关 |

### 2.2 转换消耗与兼容度关系

| 新旧宗教兼容度 | 转换消耗 | 转换耗时 | 稳定度下降 | 说明 |
|:--------------:|:--------:|:--------:|:----------:|------|
| 🟢 **高兼容** | 500~800金 | 3个月 | -10 | 如R4↔R5、R1↔R2 |
| 🟡 **中兼容** | 800~1500金 | 4个月 | -15 | 如R1↔R5、R3↔R5 |
| 🔴 **低兼容** | 1500~3000金 | 6个月 | -25 | 如R2↔R6、R1↔R6 |

> **兼容度矩阵**详见[01-世界观.md §3.6.3](01-世界观.md)。

### 2.3 转换触发方式

| 方式 | 说明 | 典型场景 |
|------|------|----------|
| **① 主动改宗** | 玩家主动发起宗教转型事件 | 参见[08-宗教.md §4](08-宗教.md)六大转型事件 |
| **② 强制同化** | 征服敌国后，宗教制度同步推行征服国宗教 | 占领他国后选择强制同化 |
| **③ 文化渗透** | 他国宗教通过商路/传教士自然传播，达到阈值后触发转型事件 | 传教士活动+文化建筑覆盖>50% |
| **④ 事件触发** | 特定剧情/危机事件推动宗教转型 | 圣女降临、圣水纯化等特殊事件 |

## 四、宗教转型与制度联动

### 4.1 宗教与政治制度联动

| 宗教 | 最佳政治匹配 | 冲突政治制度 | 联动效果 |
|------|------------|------------|----------|
| R1佛教 | 贵族议政制/宗教领袖制 | 征兵制（不杀生-10%） | 佛教+贵族制：文化+10% |
| R2儒教 | 君主专政制 | 部落酋长制（文化冲突） | 儒教+君主制：稳定+5/月 |
| R3拜火教 | 城邦市政制/贵族议政制 | 部落/民兵制 | 拜火+城邦制：商路+10% |
| R4多神教 | 城邦市政制/部落酋长制 | 无强烈冲突 | 多神+任何制度：兼容+5% |
| R5圣女教 | 宗教领袖制/君主专政制(全女版) | 封建奴隶制（女奴冲突） | 圣女+母系制：女性权威+10% |
| R6萨满教 | 部落酋长制 | 城邦市政制（定居vs游牧） | 萨满+部落制：骑兵+10% |

### 4.2 宗教转型对国家类型的影响

| 转型事件 | 国家类型影响 | 说明 |
|----------|-------------|------|
| 普通国→R5（圣女降临） | 女性比例≥50%时可能触发凤鸣觉醒 | 宗教转型→人口结构变化→国家类型可能转型 |
| 母系国→R1/R3（混合信仰） | 保持母系国不变 | 保留圣水受孕+第二宗教加成，但10%/月冲突概率 |
| 母系国→R4（回归多神） | 保持母系国不变，但女性权威下降 | 失去全部圣女教特效，女性权威-15% |
| 全女国→R1（彻底改宗） | 保持全女国不变，但失去圣水 | 人口增长依赖男奴繁殖/收养孤儿 |
| 全女国→R4（万神庇护） | 可能转为母系国 | 首现男性公民，制度可能同步转型 |

## 五、宗教转型的阶段限制

| 游戏阶段 | 可触发的宗教转型 | 限制说明 |
|----------|-----------------|----------|
| **阶段一** | 无 | 新手保护期，使用城邦初始宗教 |
| **阶段二** | 无 | 新手保护期，不可主动转换宗教 |
| **阶段三** | 基础转型事件（佛缘东来、汉化入儒等） | 可主动触发普通国家的宗教转型事件 |
| **阶段四** | 全部转型事件 + 强制同化宗教同步 | 解锁混合信仰（母系/全女国的圣佛共存、圣女拜火） |
| **阶段五** | 全部转型事件 + 强制同化深化 | 强制同化期间宗教转换消耗×1.5 |
| **阶段六** | 全部转型事件 + 圣水纯化（全女国） | 全女国可锁定R5，不可逆 |
| **阶段七** | 外部势力干预宗教转型 | 外部势力可能强迫改宗（详见[28-外部势力.md](28-外部势力.md)） |

### 5.1 强制同化期间的宗教转换限制

| 情况 | 规则 |
|------|------|
| **已选择强制同化** | 宗教转换消耗×1.5（与政治制度同步） |
| **已完成强制同化** | 宗教锁定为与最终政治制度匹配的宗教 |
| **双轨并行期间** | 宗教制度不可双轨——必须统一（宗教制度与政治/军事制度同为强制同步维度） |

## 六、宗教转换事件链

### 6.1 大规模宗教改革事件

| 事件名称 | 触发条件 | 流程 | 效果 |
|----------|----------|------|------|
| **国教改制** | 主动改宗不同宗教（非混合信仰） | ①宣布改宗→②旧宗教建筑改造/拆除（消耗500~2000金）→③新宗教建筑建设→④过渡期（6个月稳定度-15） | 完成效果：新宗教全部加成生效 |
| **混合信仰确立** | 母系/全女国从R5改宗R1/R3并保留圣水 | ①宗教对话（消耗300金）→②签署共处协议→③调整祭祀体系（消耗500金）→④过渡期（3个月） | 完成效果：保留圣水+第二宗教加成，10%/月冲突概率 |
| **宗教同化** | 强制同化中被征服国改宗 | ①征服国宗教强制推行→②被征服国寺庙改造（消耗500~1500金）→③原宗教信众安抚（消耗200~500金）→④过渡期（6个月，稳定度-10） | 完成效果：被征服国宗教统一，但原宗教信众不满持续12个月 |
