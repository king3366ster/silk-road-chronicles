## 一、发展总纲

### 1.1 核心原则

> **发展三定律**：
> 1. **生存优先**：阶段一~二是生存期，任何扩张行为都建立在粮食安全+经济盈余的基础上
> 2. **路线锁定**：阶段四是路线选择期，选择决定后续所有制度配置和发展方向
> 3. **制度适配**：阶段五是制度定型期，经济/军事/政治三大制度必须与路线和国家类型匹配

### 1.2 七大阶段发展总览

| 阶段 | 核心目标 | 势力解锁 | 关键指标 | 发展节奏 |
|------|---------|---------|---------|---------|
| **一·城邦初立** | 存活+积累 | 仅城防自卫（民兵制） | 粮食盈余>0、金库>500 | 保护期，不扩张 |
| **二·部落征途** | 整合+初步扩张 | 征兵制+雇佣兵制 | 人口>5000、军队>500 | 缓慢扩张 |
| **三·城市发展** | 城市升级+初扩 | 外交功能 | 城市≥Lv3、商路≥2条 | 稳步发展 |
| **四·丝路争霸** | 扩张+路线选择 | 商路建设+封地 | 占领/同盟≥2国 | 快速扩张 |
| **五·帝国博弈** | 帝国外交+制度定型 | 制度转型 | 占领/同盟/附庸≥5国 | 多线博弈 |
| **六·势力崛起** | 统一加速+身份升级 | 全功能+禁卫军 | ≥12国→身份升级 | 全面推进 |
| **七·一统西域** | 终极决战 | 征伐外部势力 | ≥36国+6势力处理 | 终极决战 |

### 1.3 国家等级与发展差异

| 国家等级 | 人口范围 | 起始资源 | 发展优势 | 发展劣势 | 典型发展节奏 |
|----------|---------|---------|---------|---------|-------------|
| **大国(12)** | 8,000~12,000 | 金库2000+粮800+兵500 | 人口充足、多线发展 | 管理复杂、内耗风险 | 可同时推进军事+经济 |
| **中等国(18)** | 5,000~8,000 | 金库1000+粮400+兵200 | 灵活转型、聚焦突破 | 资源有限、需精打细算 | 聚焦一条主线深耕 |
| **小国(20)** | 3,000~5,000 | 金库500+粮200+兵100 | 专注度高、外交灵活 | 人口少、军事弱、容错低 | 必须依附或差异化生存 |

## 二、三类国家发展路径

### 2.1 普通国家发展路径（36国）

> 普通国家是游戏最基础的类型，男女比55:45，男性主导。36个普通国涵盖大国12、中等国12、小国12，分布于四大区域。

#### 2.1.1 普通大国发展路径

> **代表**：乌孙(游牧)、车师(商贸)、焉耆(渔农)、疏勒(商贸)、龟兹(文化)、姑墨(美酒)、楼兰(丝路门户)、大宛(汗血宝马)、于阗(玉石)

**阶段一~二（生存期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 绿洲农耕制或游牧畜牧制开局，确保粮食盈余>200/月 |
| **军事** | 民兵制→征兵制，组建500人基础军队（男兵为主） |
| **外交** | 仅与相邻城邦建立基础贸易关系 |
| **人口** | 男农民55%+女纺织12%+男矿工8%+男牧民25%（游牧国） |

**阶段三~四（扩张期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 切换商路贸易制（商贸国）或保持游牧畜牧制（军事国），开辟2~3条跨区域商路 |
| **军事** | 扩军至2000+，解锁雇佣兵补充精锐 |
| **外交** | 占领/同盟≥2国，选择六大路线之一 |
| **路线选择** | A-君临天下（乌孙/大宛）、B-富甲丝路（疏勒/楼兰）、C-万国来朝（龟兹/于阗） |

**阶段五~六（定型期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 转庄园贡赋制（A路线）或国家专营制（B/C路线） |
| **军事** | 扩军至8000+，征兵制+贵族私兵双轨 |
| **外交** | ≥5国时处理帝国外交，≥12国时身份升级为国王/女王 |
| **制度** | 阶段五解锁制度转型，根据路线调整政治/经济/军事 |

**阶段七（终极决战）**：

| 路线 | 终极目标 | 决战方式 |
|------|---------|---------|
| A | 驱逐全部外部势力 | 独立击败四方联军 |
| B | 同盟≥2个势力 | 经济封锁敌对势力 |
| C | 臣服1个势力借力 | 文化同化+宗主协助 |
| E | 利用势力矛盾 | 外交瓦解敌对联盟 |
| F | 臣服1个势力 | 联合宗主击退敌对 |

#### 2.1.2 普通中等国发展路径

> **代表**：蒲类(游牧)、危须(铁矿)、温宿(石材)、尉犁(渔猎)、且末(玉石)、精绝(古物)、莎车(商贸)、赤谷国(母系)等

**核心策略**：聚焦一条主线深耕，不贪多线

| 阶段 | 核心行动 | 关键指标 |
|------|---------|---------|
| 一~二 | 确保粮食安全+特产产出 | 粮食盈余>100/月、特产收入>50金/月 |
| 三~四 | 特产外交+聚焦路线 | 商路≥1条、同盟≥1国 |
| 五~六 | 制度定型+依附/差异化 | ≥5国、路线核心指标达标 |
| 七 | 终极决战 | 路线胜利条件 |

**推荐路线**：中等国建议选择E-纵横捭阖（外交灵活）或B-富甲丝路（特产贸易），避免A-君临天下（兵力不足）

#### 2.1.3 普通小国发展路径

> **代表**：乌垒(汉驻)、渠犁(汉屯)、尉头(山口)、小宛(隐匿)、戎卢(驼队)、皮山(玉石中转)等

**核心策略**：依附求存+差异化突破

| 阶段 | 核心行动 | 关键指标 |
|------|---------|---------|
| 一~二 | 依附大国/帝国求生存 | 与≥1大国建立同盟或臣服关系 |
| 三~四 | 差异化特产+路线选择 | 特产收入占总收入>40% |
| 五~六 | 制度定型+借势扩张 | 利用宗主/盟友力量扩张 |
| 七 | 终极决战 | 路线胜利条件 |

**推荐路线**：小国建议选择F-天朝藩屏（依附帝国）或E-纵横捭阖（外交生存），C-万国来朝也可（文化差异化为王）

### 2.2 母系国家发展路径（8国）

> 母系国家男女比30:70，女性主导但包容男性。8个母系国：月氏国、赤谷国、瑶池国、玄女国、素女国、青鸾国、灵山国、玉河国

#### 2.2.1 母系大国发展路径

> **代表**：月氏国(游牧骑兵)、瑶池国(药草圣地)

**阶段一~二（生存期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 游牧畜牧制（月氏）或特色精工制（瑶池），确保粮食+特产双线产出 |
| **军事** | 70%男兵+30%女兵，女兵限中高级精锐 |
| **人口** | 男劳奴分配矿场/伐木场弥补重体力缺口；圣水受孕+优种外交补充人口增长 |
| **外交** | 与母系/全女国优先建交，好感积累快（联姻效果+50%） |

**阶段三~四（扩张期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 切换国家专营制（瑶池圣水/月氏马匹专营） |
| **军事** | 女骑兵精锐分队+男兵主力，扩军至1500+ |
| **外交** | 姐妹之盟（母系圈联姻同盟），占领/同盟≥2国 |
| **路线选择** | D-凤鸣昆仑（首选）或A-君临天下（月氏骑兵路线） |

**阶段五~六（定型期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 国家专营制+商路贸易制双轨 |
| **军事** | 母系联军（多国女兵协同），扩军至5000+ |
| **外交** | 母系文明圈整合，应对父权联盟反扑 |
| **制度** | 可触发"女儿当国"（母系→全女）或保持母系 |

#### 2.2.2 母系中等国发展路径

> **代表**：赤谷国(精铁)、玄女国(兵法)、青鸾国(玉雕)

**核心策略**：特产专营+母系外交圈

| 阶段 | 核心行动 | 关键指标 |
|------|---------|---------|
| 一~二 | 特产聚焦+男劳奴补缺口 | 特产收入>80金/月、男劳奴占比10% |
| 三~四 | 专营特产+姐妹之盟 | 专营收入>200金/月、同盟≥2母系国 |
| 五~六 | 母系圈整合+制度定型 | ≥5国、D路线核心指标 |
| 七 | 终极决战 | D路线胜利条件 |

#### 2.2.3 母系小国发展路径

> **代表**：素女国(琴艺)、灵山国(药草)、玉河国(美玉)

**核心策略**：差异化精工+依附母系圈

| 阶段 | 核心行动 | 关键指标 |
|------|---------|---------|
| 一~二 | 特色精工制聚焦独占特产 | 特产收入>60金/月 |
| 三~四 | 特产外交赠礼+联姻同盟 | 外交好感≥60（≥3国） |
| 五~六 | 依附瑶池/月氏等母系大国 | 借势扩张+制度定型 |
| 七 | 终极决战 | D路线胜利条件（依附母系圈整体胜利） |

**关键生存逻辑**：母系小国人口仅3000~5000，军事极弱，必须通过特产外交+联姻同盟在母系文明圈中找到位置，不能独立对抗大国

### 2.3 全女性国家发展路径（6国）

> 全女国男女比0:100，纯女性社会。6个全女国：西梁女国、东女国、苏毗女国、阿玛宗、斯基泰、弱水国

#### 2.3.1 全女大国发展路径

> **代表**：西梁女国(圣水丝绸)、东女国(织锦商贸)

**阶段一~二（生存期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 特色精工制开局，子母河水/天衣丝绸精工产出为核心收入 |
| **军事** | 100%女兵，织女卫队+水月弓手（西梁）或均衡型步骑弓（东女） |
| **人口** | 圣水受孕+优种外交+侍女租借三线并行，月增长率最高1.5% |
| **粮食** | 粮食自给率仅50~60%，必须用特产出口换粮食进口 |
| **男奴** | 可从斯基泰/阿玛宗奴市购买男奴，**只能选择立即消耗（男奴繁殖）**，无消化期 |

**阶段三~四（扩张期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 切换商路贸易制（特产+商路双引擎）或国家专营制（垄断定价） |
| **军事** | 女兵扩军至1000+，女兵总加成+20% |
| **外交** | 优种外交+侍女租借建立外交网络，同盟≥2国 |
| **路线选择** | D-凤鸣昆仑（首选）或B-富甲丝路（东女商贸路线） |

**阶段五~六（定型期）**：

| 维度 | 策略 |
|------|------|
| **经济** | 国家专营制锁定——子母河水专营（西梁）或东女织锦专营（东女） |
| **军事** | 女兵精锐军团+雇佣兵补充，扩军至3000+ |
| **外交** | 姐妹之盟+文明圈效应（每统一1母系/全女国→全属性+3%） |
| **制度** | 保持全女制或触发"凤归母巢"（全女→母系，开放男性移民补劳动力） |

#### 2.3.2 全女中等国发展路径

> **代表**：阿玛宗(骑射)、斯基泰(骑射)、苏毗女国(商贸)

**核心策略**：军事以战养战（阿玛宗/斯基泰）或商贸转口（苏毗）

## 三、四大区域发展特色

### 5.1 制度1：绿洲农耕制 🌾

#### 普通国家应用

| 维度 | 策略 |
|------|------|
| **人口分配** | 农业55%（男农民为主）+矿工8%+伐木8%+手工业12%+商业7%+士兵10% |
| **核心循环** | 男农民(3粮/月)→粮食盈余→养更多男兵→军事扩张→更多农民→正循环 |
| **奴隶策略** | 购买男劳奴(50金)分配农场，快速拉升粮食产出 |
| **出口策略** | 粮食盈余→酿造美酒(2粮→1美酒)出口，或直接贸易换金币和铁矿 |
| **转型时机** | 人口>5000且粮食盈余>1000/月时，可转商路贸易制 |

#### 母系国家应用

| 维度 | 策略 |
|------|------|
| **人口分配** | 农业50%（女农民为主）+矿工6%(男奴替代)+手工业18%(女纺+采药)+商业10%+士兵11% |
| **性别劣势弥补** | 女农民(+2.5粮)效率为男农民83%，需多配10~15%农业人口；矿工/伐木由男劳奴替代 |
| **核心特点** | 纺织+采药天然优势，粮食自给率略低但手工业附加值更高 |
| **奴隶策略** | 男劳奴分配矿场/伐木场补重体力缺口；母系国选择男奴可立即消耗(男奴繁殖)或填充劳力(需1回合消化期) |

#### 全女性国家应用

| 维度 | 策略 |
|------|------|
| **人口分配** | 农业55%（多配20%弥补效率差）+手工业25%（纺织/采药双优势）+士兵10% |
| **性别劣势弥补** | 无男性，女农民效率仅为男农民83%，矿工完全由女劳奴替代 |
| **核心优势** | 纺织+100%、采药+100%，用高附加值手工业出口换粮食进口 |
| **奴隶策略** | 女劳奴大量购买（全女国价格-10%）；购买男奴只能立即消耗（男奴繁殖），无消化期 |
