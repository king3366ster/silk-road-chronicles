### 1.1 类型互斥与强制绑定（基础准则）

| 约束 | 内容 |
|------|------|
| **圣女教 ↔ 父系国** | 父系国不可信奉圣女教（主/副均不可）；强制接触触发"圣女教镇压"（稳定-20、女性叛乱+20%/月）；改宗事件中父系国无"圣女降临"选项 |
| **拜火教/萨满教 ↔ 母系/全女国** | 母系国与全女国不可信奉拜火教与萨满教（主/副均不可）；强制传教触发"信仰排斥"（稳定-15/月、传教士被驱逐）；改宗事件中母系/全女国无"圣火东传/万物归灵"选项 |
| **圣女教 ⇒ 全女国（强制绑定·立国约定）** | 全女国必须信奉圣女教（主/副必含其一），**不可弃圣女教**——圣水受孕是全女性社会的人口根基。主信仰可改（圣女教自动转副保留），但不得移除圣女教；仅当国家类型转型（全女→母系/普通）后约束解除。母系国不受此限，可完全弃圣女教改宗 |

> 圣女教与父系国的男权秩序、拜火教/萨满教与母系/全女的女性神圣秩序根本冲突；圣女教则是全女类型的立国之本（「女儿当国」的必要条件，见[01-世界观.md](01-世界观.md)§6.1）。初始信拜火教/萨满教的母系/全女国不存在，初始全女国均含圣女教（初始分配已按约束校验）。

## 三、圣女教双信仰特殊化（核心）

> **基础准则**：圣女教与任何宗教🟢高兼容；双信仰时圣女教恒为**副信仰**，主信仰享全额加成（不走通用共存折扣），走以下五组合特殊化：

| 组合 | 名称 | 效果 | 典型国 |
|------|------|------|--------|
| 佛教+圣女教 | **水佛同源** | 佛教全额；圣水受孕保留；伤兵恢复+25% | 西梁、瑶池、灵山、精绝 |
| 儒教+圣女教 | **圣母礼制** | 儒教全额；宗法认可女性继承；"女性参政-15%"惩罚取消 | （初始无；前儒教国经「圣女降临」可成此组合） |
| 拜火教+圣女教 | **圣水圣火** | 拜火全额；受孕保留；圣火由圣女主持（维护+25金/月，冲突-5%） | （初始无——拜火教与母系/全女互斥；仅普通国经双改宗可成此组合） |
| 多神教+圣女教 | **万神圣女** | 多神全额；圣女入万神殿；受孕保留；节日满意+5 | 东女、玄女、扜弥、斯基泰、阿玛宗、月氏、青鸾、玉河 |
| 萨满教+圣女教 | **圣女即萨满** | 萨满全额；圣女兼大萨满；受孕保留；祭祀成本-50% | 蒲犁（普通国萨满教+圣女教） |

> 受孕在所有组合保留（上限全女0.9%/母系0.6%/普通0.3%）；父系国不适用（禁圣女教）；改宗主信仰时圣女教副可保留。**全女国不可弃圣女教（立国约定）**——主信仰变更时圣女教自动转副保留，仅当类型转型（全女→母系/普通）后约束解除。

### 4.2 共存折扣与不可共存

- **折扣公式**：主加成×系数（天然亲和圣女教+萨满教为70%｜兼容组合60%｜困难组合50%）；副加成再×50%；惩罚加重+15~30%
- **不可共存组合**：儒教×拜火教、儒教×萨满教、拜火教×萨满教、佛教×萨满教（同城邦15%/月触发冲突事件；连续3月未化解→强制宗教暴动，须选完全同化或分裂）
- **同化过渡期**：完全同化12月（稳-10/月）｜共存6月（稳-5/月）｜多神教执行仅6月（"万神归宗"过渡惩罚减半）

## 五、宗教转型

### 5.1 双通道总览

| 通道 | 方式 | 惩罚 |
|------|------|------|
| **①主动改信**（内生觉醒） | 条件满足后每月10%概率触发事件，可拒绝（12月冷却） | 接受无转型惩罚（稳定惩罚减半） |
| **②渗透传教** | 阈值链（见5.3） | 阈值阶段负面效果 |
| **③征服/附庸强制同化** | 与政治/军事制度同步强制改宗，不可拒 | 过渡期12月 |
| **④经济制裁** | 债务≥5,000金持续12月/贸易垄断/封锁施压 | 可拒但受制裁 |

### 5.2 主动改信事件（关键条件）

| 事件 | 方向 | 条件 | 注意 |
|------|------|------|------|
| 🕊️ 佛缘东来 | →佛教 | 接壤佛教国+文化Lv3+库≥500 | 圣女教转副成「水佛同源」·受孕保留；**全女国不可弃圣女教（立国约定，无彻底皈依选项）**；母系国可选彻底皈依弃圣女教——失去圣水受孕（可经「圣女降临」重引解锁） |
| 📜 礼乐教化 | →儒教 | 汉结盟/臣服+稳≥60 | 全女须经圣母礼制（圣女教转副保留受孕） |
| 🔥 圣火东传 | →拜火教 | 帕提亚贸易≥12月+库≥500 | **父系/普通限定**（母系/全女互斥） |
| 🏛️ 万神归宗 | →多神教 | 稳≥60 | 放弃旧教稳-15，过渡惩罚减半 |
| 💧 圣女降临 | →圣女教 | 女性≥50%+接壤+关系≥40 | **父系禁选**；副信仰传入（无圣女教国）可解锁受孕且主信仰不变 |
| 🪶 万物归灵 | →萨满教 | 骑兵≥40%+草原/山地 | **父系/普通限定**（母系/全女互斥） |

**母系专属**：母佛交融（稳≥70，受孕保留）｜礼乐入母系（稳≥70）｜旧神回溯（稳<40，失圣女教特效）｜圣女回归。
**全女专属**：天女礼佛（贵霜建交+文化Lv4；圣女教转副「水佛同源」·受孕保留——**全女国不可弃圣女教·立国约定，无彻底皈依选项**）｜万神庇护（稳<30危机解除）｜**圣水纯化**（男=0+稳≥80持续24月→**永久锁定圣女教**：受孕上限+50%至1.35%/月、建筑产出+25%，代价科技-25%商路-20%）｜纯洁分裂叛乱（改宗+稳<40→守旧派城邦独立）。

### 5.3 渗透传教（阈值链）

```
传教力 = 宗教建筑等级×1 + 传教士魅力÷20 + 商路数×0.5 + 目标好感÷40
抵抗力 = 目标稳定÷20 + 国教凝聚力(多神教+2；宗教领袖制+3) + 制度匹配修正
```

传教士派遣100~300金/人（+2%/月，魅力≥60→+3%；10%/月被驱逐）。阈值：≥10%异兆（稳-2/月）→≥30%教派之争（稳-5/月，可选改宗/清洗/共存）→≥50%信仰危机（稳-10/月；接受改宗稳→60，拒绝30%叛乱）→≥70%改宗革命（强制改宗，拒绝稳-20/月+暴动）。**反渗透**：禁教令（异教徒-2%/月，代价关系-20）、驱逐传教士、国教强化（抵抗+2）。

### 5.4 经济制裁改宗

触发（任一）：债务≥5,000金持续12月｜≥70%进出口依赖施压国（商路Lv4+）｜被经济封锁（Lv5）。选择：①改宗（圣女教副可保留）②建施压国宗教建筑（主信仰不变）③接纳圣女教副信仰。接受→债务减免10~20%+稳定惩罚减半；拒绝→税率+20%、利息+5%/月、6月后稳-5/月。**限制**：不可对父系国要求圣女教、不可要求目标类型禁信的宗教、**不可要求全女国弃圣女教**（只能变更其主信仰）。

### 5.5 转换基本规则与消耗（系统层）

| 规则项 | 说明 |
|--------|------|
| **转换前提** | 稳定度≥60+满足对应宗教转型事件条件（见§5.2） |
| **冷却时间** | 转换后间隔8个月方可再次转换 |
| **转换耗时** | 3~6个月过渡期（过渡期稳定-10/月，原宗教信众不满） |
| **稳定影响** | 转换后稳定-15~-25（与新旧宗教兼容度负相关） |

**消耗与兼容度关系**：

| 新旧宗教兼容度 | 转换消耗 | 耗时 | 稳定下降 |
|:--------------:|:--------:|:----:|:--------:|
| 🟢 高兼容 | 500~800金 | 3个月 | -10 |
| 🟡 中兼容 | 800~1500金 | 4个月 | -15 |
| 🔴 低兼容 | 1500~3000金 | 6个月 | -25 |

**强制同化期间限制**：同化期间宗教转换消耗×1.5；同化完成后宗教锁定为与最终政体匹配的宗教；双轨期间宗教不可双轨（与政治/军事同属强制同步维度）。**阶段限制**：阶段一~二保护期不可转换；阶段三起基础转型事件；阶段四解锁混合信仰；阶段六解锁全女国"圣水纯化"；阶段七外部势力可强迫改宗。

### 5.6 宗教转换事件链

| 事件名称 | 流程 | 完成效果 |
|----------|------|----------|
| **国教改制**（彻底改宗） | 宣布改宗→旧宗教建筑改造/拆除（500~2000金）→新宗教建筑建设→过渡期6月（稳定-15） | 新宗教全部加成生效 |
| **混合信仰确立**（母系/全女圣女教+第二信仰） | 宗教对话（300金）→共处协议→祭祀体系调整（500金）→过渡3月 | 保留圣水+第二宗教加成，10%/月冲突概率 |
| **宗教同化**（强制同化中被征服国改宗） | 征服国宗教强制推行→寺庙改造（500~1500金）→原信众安抚（200~500金）→过渡6月（稳定-10） | 宗教统一，原信众不满持续12月 |

## 六、征服改宗与异教徒处置

> 强制改宗与政治/军事制度同步（过渡期12月，多神教仅6月）；**对全女国强制改宗仅变更主信仰（圣女教恒为副保留）——仅当强制同化引发国家类型转型（全女→母系/普通）时方可移除圣女教**。异教徒处置四策：A转化（12月5%/月）｜B降奴｜C驱逐（人口-10~20%）｜D处死（人口-5~10%）。
