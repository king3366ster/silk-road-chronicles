## 一、武将双轨体系总论

### 1.1 双轨制核心概念

> 武将系统分为**两套独立但可交互的体系**：**势力武将/文官**（归属国家）和**玩家私有武将/文官**（归属玩家个人）。阶段四起玩家可委任私有文官/武将担任势力官职，阶段五以后逐步融合，阶段六完成合并。

| 维度 | 势力武将/文官 | 玩家私有武将/文官 |
|------|-------------|----------------|
| **归属** | 国家/势力 | **玩家角色个人** |
| **忠诚对象** | 国家/统治者 | **玩家角色** |
| **获取方式** | 城邦初始+游戏事件触发（科举选拔/察举推荐/军功提拔/外交事件等） | 奴隶培养/任务奖励/掠夺敌国/招募探索/敌国招降/势力拉拢 |
| **消耗** | 国库俸禄 | **玩家私库** |
| **官职限制** | 按国家制度任命 | **官职不得高于玩家**；阶段三前以侍女/侍卫/随从/幕僚身份存在 |
| **数量上限** | 无硬性上限（俸禄约束） | 受玩家身份等级限制 |
| **阶段四核心** | — | **可委任私有文官/武将担任势力官职** |
| **阶段五核心** | — | **拉拢势力武将为玩家武将** |
| **阶段六核心** | **排除异己+合并双轨** | **合并完成** |

### 1.2 双轨阶段演进（对齐01-世界观七大阶段）

| 阶段 | 玩家身份 | 势力武将 | 玩家私有随从/武将 | 两轨关系 |
|------|---------|---------|----------------|---------|
| **一·城邦初立** | 奴隶/公民 | 国家已有（不可控） | 首批侍女/随从1~3人 | 独立运行 |
| **二·部落征途** | 幕僚/参谋 | 可下达部分指令 | 侍女/随从任务解锁 | 独立运行 |
| **三·城市发展** | 初级官员 | 可下达部分指令 | 侍卫/幕僚→协助城防 | 侍卫协助城邦 |
| **四·丝路争霸** | 中高级官员 | 完全控制 | **侍女/侍卫/幕僚→正式文官/武将**；可委任势力官职 | 可执行相同任务 |
| **五·帝国博弈** | 丞相/国师 | 完全控制 | **拉拢势力武将** | 交互开始 |
| **六·势力崛起** | 势力实际统治者※ | **排除异己后合并** | **合并** | 统一体系 |
| **七·一统西域** | 西域霸主/女帝 | 统一体系 | 统一体系 | 无区分 |

> **阶段三→四关键转变**：阶段三之前，玩家私有人员均以**侍女/侍卫/随从/幕僚**身份存在（无正式官职、无独立统兵权、执行辅助任务）。进入阶段四（玩家身份为中高级官员），私有人员正式晋升为**文官/武将**，且可被**委任担任势力的官职**（如太守、将军等），但官职等级不得高于玩家自身等级。

> **※阶段六实际统治者身份因国家类型与性别而异**：普通国→国王/女王/汗王；母系国→女王/摄政王(男)/教皇(男)；全女国→女帝/圣女(女)/唯一合法男性(男，需忠诚度≥80)；宗教领袖制→教皇/圣女/宗教领袖

#### 2.2.3 官职委任规则（阶段四核心）

> **核心规则**：阶段四起，玩家可委任**私有文官/武将**担任**势力官职**，使私有人员在国家体系中发挥正式作用。

| 规则 | 说明 |
|------|------|
| **官职上限** | 私有文官/武将担任的势力官职**不得高于玩家自身等级对应的官职** |
| **双重忠诚** | 委任后私有人员对玩家忠诚不变，同时获得对国家的职责加成 |
| **俸禄变化** | 委任后俸禄由**国库支出**（减轻私库负担），但玩家仍保留其人事调配权 |
| **召回权** | 玩家可随时召回委任的私有人员（消耗1回合），召回后俸禄回归私库 |
| **阶段限制** | 阶段三及之前：私有人员仅以侍女/侍卫/随从/幕僚身份存在，不可担任势力官职 |

**官职等级对应表**：

| 玩家等级 | 玩家对应官职 | 可委任私有人员的最高官职 |
|----------|------------|----------------------|
| Lv5~6 | 初级官员 | 什长/书吏 |
| Lv7~8 | 中高级官员 | 百夫长/主簿 |
| Lv9 | 丞相/国师 | 千夫长/长史 |
| Lv10 | 统治者 | 万夫长/别驾（阶段六合并后无限制） |

### 2.3 势力武将获取途径

> **核心设计**：势力武将由**城邦初始武将**和**游戏事件触发**获得的武将组成。事件触发是势力武将持续补充的主要来源。

#### 2.3.1 城邦初始武将/文官

| 国家类型 | 初始人数 | 武将:文官比例 | 说明 |
|----------|:-------:|:----------:|------|
| **大国**（12个） | **9人** | 根据国家属性调整 | 好战国武将多，文教国文官多 |
| **中等国**（18个） | **7人** | 根据国家属性调整 | 好战国武将多，文教国文官多 |
| **小国**（20个） | **5人** | 根据国家属性调整 | 好战国武将多，文教国文官多 |

> **初始武将/文官属性**：平均属性50-70，忠诚度初始80（高于其他来源）。男女比例：普通国家5:5，母系国家3:7，全女性国家100%女性。

#### 2.3.2 游戏事件触发获取

> 势力武将的持续补充主要通过游戏内事件触发，而非玩家主动操作。以下是四种事件触发途径：

**途径一：科举选拔**

| 维度 | 规则 |
|------|------|
| **触发条件** | 城市等级≥Lv3，每年春季自动举行 |
| **产出** | 1~2名文官，属性侧重智力+政治 |
| **男女比例** | 普通国家6:4，母系国家3:7，全女性国家100%女性 |
| **消耗** | 200~400金（国库支出） |
| **属性范围** | 平均50-70 |
| **忠诚度** | 初始60 |

**途径二：察举推荐**

| 维度 | 规则 |
|------|------|
| **触发条件** | 每回合有基础概率，由现有武将/文官推荐民间人才（魅力≥60的武将/文官推荐概率+15%） |
| **产出** | 不定期，大国每年约1~2人，中等国约1人，小国约0~1人 |
| **男女比例** | 普通国家6:4，母系国家3:7，全女性国家100%女性 |
| **消耗** | 100~300金（国库支出） |
| **属性范围** | 平均45-65（低于科举，因未经系统训练） |
| **忠诚度** | 初始50 |
| **推荐者关系** | 被推荐者与推荐者形成"门生"关系，推荐者忠诚+5 |

**途径三：军功提拔**

| 维度 | 规则 |
|------|------|
| **触发条件** | 士兵参与战斗≥5场后有概率触发「军功晋升」事件 |
| **产出** | 1名武将，属性侧重统率+武力 |
| **男女比例** | 与军队性别构成一致 |
| **消耗** | 150~350金（国库支出）+ 赐予兵器/坐骑 |
| **属性范围** | 平均55-70（实战经验丰富） |
| **忠诚度** | 初始70（高于其他来源，因从底层提拔） |
| **特殊** | 保留士兵时代的兵种专精（如原为骑兵→骑战系技能起步） |

**途径四：外交事件**

| 维度 | 规则 |
|------|------|
| **触发条件** | 与他国外交关系变化时触发（联姻/朝贡/同盟达成/附庸确立等） |
| **产出** | 不定期，取决于外交事件规模 |
| **联姻获将** | 联姻成功→获得对方1名武将（属性60-80，忠诚初始55） |
| **朝贡获将** | 小国朝贡→可能附带1名武将作为"质子/护卫"（属性40-60，忠诚初始45） |
| **同盟/附庸获将** | 同盟/附庸国可能派遣武将支援（临时归属，非永久） |
| **消耗** | 外交事件本身的费用（无额外消耗） |

### 2.4 武将/文官任务系统

> **核心规则**：武将和文官有明确的职责分工。武将专注于军事领域，文官专注于内政领域。任务设计对齐制度与发展需求（出征、平叛、外交、农业、贸易、稳定度提升等）。**武将不可执行文官任务，文官不可执行武将任务。**

## 三、玩家私有武将/文官体系

### 3.1 阶段三前：侍女/侍卫/随从/幕僚

> **核心规则**：阶段三之前，玩家私有人员均以**侍女/侍卫/随从/幕僚**身份存在，无正式官职，无独立统兵权，仅执行辅助任务。进入阶段四后，这些人正式晋升为**文官/武将**。

### 5.1 幕府系统（阶段五核心解锁）

> 玩家达到阶段五（丞相/国师身份，Lv≥8）时解锁**幕府**——玩家私人权力机构，独立于国家官僚体系。

| 幕府职位 | 人数 | 等级要求 | 功能 |
|----------|:---:|:------:|------|
| 幕僚长 | 1 | Lv9+ | 管理全部玩家武将 |
| 首席文官 | 1 | Lv7+ | 代行内政/外交 |
| 首席武将 | 1 | Lv7+ | 代行军事指挥 |
| 幕僚 | ≤5 | Lv5+ | 执行文官/武将任务 |
| 侍卫长 | 1 | Lv6+ | 管理近卫军/私兵 |

### 5.2 拉拢势力武将机制

> **阶段五核心玩法**：将势力武将拉拢为玩家武将。拉拢成功后武将脱离国家体系，转为玩家个人所有。

#### 拉拢条件

| 条件 | 说明 |
|------|------|
| 玩家等级 | ≥Lv8 |
| 游戏阶段 | ≥阶段五 |
| 目标武将忠诚度 | ≤59（动摇或不满） |
| 目标武将派系 | 自身派最容易(★)、改革派中等(★★)、王权派最难(★★★★) |
| 幕府职位空缺 | 有对应职位空位 |

#### 拉拢方式（三种）

| 方式 | 消耗 | 成功概率 | 适合对象 |
|------|------|:-------:|---------|
| **私下赠礼** | 500~2000金+特产/宝物 | 30%~50% | 自身派、忠诚度40~59 |
| **利益承诺** | 承诺更高职位/封地/特权 | 40%~60% | 改革派、自身派 |
| **理念共鸣** | 完成特定剧情对话+玩家魅力≥70 | 50%~70% | 改革派 |

#### 拉拢流程

```
1. 选择目标势力武将/文官（忠诚度≤59）
2. 选择拉拢方式（赠礼/承诺/共鸣）
3. 计算成功概率：
   基础概率 = 方式基础概率
   + 玩家魅力加成(魅力每10点+5%)
   + 忠诚度加成(越低越容易：40~59时+0%，20~39时+10%，0~19时+20%)
   + 派系匹配加成(自身派+10%，改革派+0%，王权派-20%)
   - 目标武将统率/智力抵抗(每10点-3%)
4. 随机判定
5. 成功→武将转入幕府(忠诚度重置为60)
6. 失败→武将忠诚度-10，若为王权派则可能向统治者告密(触发"阴谋暴露"事件)
```

#### 拉拢失败后果

| 失败类型 | 后果 | 处理 |
|---------|------|------|
| 被拒绝 | 目标忠诚度-5，3月冷却期 | 可再次尝试 |
| 被告密 | 王权派向统治者告密→触发"阴谋暴露"事件 | 玩家政治影响力-15，3月内不可拉拢 |
| 反向策反 | 自身派武将被敌国收买→叛逃 | 失去武将，好感下降 |

## 六、阶段六·排除异己与势力合并

### 6.1 排除异己机制

> **阶段六核心玩法**：玩家成为统治者后，必须**排除异己**——清除不忠诚的势力武将/文官，确保权力稳固。排除异己后，势力武将与玩家武将合并为统一体系。

#### 排除异己方式（四种）

| 方式 | 适用对象 | 效果 | 风险 |
|------|---------|------|------|
| **🤐 流放** | 忠诚度20~39(不满) | 武将离开势力，不带走军队 | 稳定度-5；被流放者可能投敌 |
| **⛓️ 降奴** | 忠诚度0~19(背叛) | 武将变为奴隶/战奴 | 稳定度-2；但武将属性归零 |
| **💀 处决** | 忠诚度0~19+有叛乱行为 | 武将死亡，震慑效果 | 稳定度-10短期(+15长期)；其他武将忠诚度+10(恐惧)或-15(反感) |
| **🤝 收买** | 自身派+忠诚度40~59 | 花费1000~3000金收买→忠诚度→80 | 成本高；但保留武将 |

#### 排除异己判定流程

```
1. 进入阶段六 → 触发"权力审查"事件
2. 所有势力武将/文官进行忠诚度重评：
   - 王权派：若玩家身份为正统统治者→忠诚+20；若为篡权者→忠诚-20
   - 改革派：若玩家推动改革→忠诚+15；若保守→忠诚-10
   - 自身派：根据玩家势力实力判定(国力前3→忠诚+10；否则-5)
3. 忠诚度重评后，低于40的武将自动标记为"异己"
4. 玩家逐个决定异己的处理方式（流放/降奴/处决/收买）
5. 处理完毕后→势力武将与玩家武将合并
```

### 6.2 势力合并机制

> 排除异己完成后，势力武将/文官与玩家私有武将/文官**合并为统一体系**。合并规则如下：

| 合并前 | 合并后 | 说明 |
|-------|-------|------|
| 势力武将(忠诚≥60) | **玩家武将** | 忠诚对象转为玩家 |
| 势力文官(忠诚≥60) | **玩家文官** | 忠诚对象转为玩家 |
| 玩家私有文官/武将(Lv5+) | **正式文官/武将** | 保留等级和加成 |
| 玩家侍女/随从(Lv1~4) | **幕府随从** | 保留随从身份，辅助幕府运作 |
| 势力武将(忠诚<40) | **被排除** | 流放/降奴/处决/收买后处理 |
| 玩家私兵 | **近卫军→禁卫军** | 阶段六升级为近卫军(3,000人)，阶段七升级为禁卫军(5,000人) |

**合并后数量上限**：阶段六无上限（受俸禄/私库约束）

## 七、贵族私兵系统

### 7.1 私兵核心概念

> 私兵是玩家从**封地招募**的个人军队，不从国家兵源征召，不受国家军事制度约束。私兵是玩家权力上升的核心军事保障，阶段六时升级为**禁卫军**。

#### 私兵核心规则

| 规则 | 说明 |
|------|------|
| **指挥权** | 私兵**只能由玩家或玩家专属武将（私有武将/幕府武将）率领**，不可交由势力武将指挥 |
| **数量上限** | 阶段五雏形500人 → 阶段六**近卫军3,000人**（贵族私兵制正式解锁）→ 阶段七**禁卫军5,000人**（对齐04-制度.md4.5节），不可突破 |
| **战斗力** | 私兵战斗力**高于国家正规军**（基础战力×1.2），因忠诚度高+装备自选+训练定制 |
| **性别与阶级** | 私兵**不受性别和阶级限制**——公民/奴隶/战奴均可编入私兵，且**不计入军队性别比例**（同雇佣兵规则，见[05-人口.md](05-人口.md)1.5.3）；全女国因全国无男性，私兵仍为全女兵 |
| **维护来源** | 从玩家私库支出，不消耗国库 |
| **战损补充** | 从封地人口补充（含专属奴隶），补充速度-20%但忠诚度+15 |

#### 私兵专属与优势用途

#### 私兵护卫与反暗杀系统

> 私兵是**保护玩家人身安全**的唯一军事力量。异己武将、间谍、叛军均可能对玩家实施暗杀，私兵负责护卫与反制。

| 威胁来源 | 触发条件 | 暗杀概率 | 私兵护卫效果 |
|----------|----------|:--------:|-------------|
| **异己武将暗杀** | 阶段六排除异己期间 | 5%~15%/月 | 私兵≥200→概率-80%；侍卫长武力≥70→-90% |
| **间谍暗杀** | 敌国谍报任务 | 3%~10%/次 | 私兵≥100→概率-70%；侍卫智力≥60→提前2回合预警 |
| **叛乱军暗杀** | 叛乱期间玩家亲临前线 | 10%~25%/战 | 私兵≥500→概率-85%；禁卫军→-95% |
| **后宫阴谋** | 阶段六后宫势力不满 | 2%~8%/月 | 侍卫长+女侍卫≥3→-75% |
| **保守势力暗杀** | 玩家夺权后保守势力反扑 | 5%~20%/月 | 私兵≥300→-80%；禁卫军→-95% |

**反暗杀机制**：
- 私兵护卫成功→暗杀者被擒获→可审讯获取情报
- 私兵护卫失败→玩家受伤（战力-30%，3月恢复）或死亡（游戏结束）
- **禁卫军护卫**：阶段六后禁卫军接管护卫，暗杀概率≤1%

### 8.1 三大兵种与相克关系

> **核心规则**：正规军三大兵种为**步兵、骑兵、弓骑兵**，三者之间存在明确的相克关系，形成战术博弈核心。

```
【兵种相克循环】

  步兵 ──克制+20%──→ 骑兵（长矛拒马克制冲锋）
   ↑                     │
   │克制+15%             │克制+20%
   ↓                     ↓
  弓骑兵 ←──克制+20%── 骑兵（快速突入远程阵地）
   
  弓骑兵 ──克制+15%──→ 步兵（远程消耗步兵阵型）
```

| 攻方→守方 | 步兵 | 骑兵 | 弓骑兵 |
|-----------|:----:|:----:|:------:|
| **步兵** | ×1.0 | **×1.2**（长矛拒马） | ×0.85（被远程消耗） |
| **骑兵** | ×0.8（冲锋被拒） | ×1.0 | **×1.2**（快速突入） |
| **弓骑兵** | **×1.15**（远程消耗） | ×0.8（被近身突击） | ×1.0 |

> **相克加成计算**：实际伤害 = 基础伤害 × 克制系数。相克关系适用于所有等级的兵种。

### 8.2 兵种培养链路

> 详细兵种名称、属性、等级体系见[05-人口.md 5.3节](05-人口.md)。此处概述三大兵种的培养路径与战略定位。

```
【步兵·铜墙铁壁】
公民/战奴→新兵(Lv0)→Lv1步兵→Lv2步兵→Lv3步兵
定位：正面战场核心，克制骑兵，被弓骑兵克制
特色：高防御、破阵/坚守，攻城/守城主力

【骑兵·风雷突击】
公民/战奴→新兵(Lv0)→Lv1骑兵→Lv2骑兵→Lv3骑兵
定位：快速突击力量，克制弓骑兵，被步兵克制
特色：高机动、冲锋伤害，追击/游击主力

【弓骑兵·远程压制】
公民/战奴→新兵(Lv0)→Lv1弓骑→Lv2弓骑→Lv3弓骑
定位：远程压制力量，克制步兵，被骑兵克制
特色：射程优势、hit-and-run，齐射/骚扰主力

【升级条件】（详见05-人口.md 5.3.4节）
新兵→Lv1：武将训练3回合+10金/人
Lv1→Lv2：武将训练6回合+20金/人+战斗≥2场
Lv2→Lv3：武将训练10回合+30金/人+战斗≥5场+统率≥60
```
