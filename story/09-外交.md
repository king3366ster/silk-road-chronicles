## 一、外交系统总论

> **核心设计**：外交系统不是简单的"好感度→操作解锁"线性模型，而是**与国家类型、政治制度、经济制度、宗教信仰深度耦合**的立体博弈系统。不同国家类型的外交有**额外奖励和惩罚，但不禁止任何操作**——玩家可以通过特定手段突破限制，但需付出额外代价。

### 1.1 外交三维度

| 维度 | 说明 | 影响因素 |
|------|------|---------|
| **关系维度** | 好感度等级决定可执行操作的基础概率 | 国家类型/历史互动/赠礼/战争 |
| **制度维度** | 政治制度+经济制度影响外交偏好和成本 | 制度匹配度/制度冲突系数 |
| **信仰维度** | 宗教信仰影响外交深度和特殊操作 | 信仰兼容度/传教影响/异教处理 |

### 1.2 外交核心原则

| 原则 | 说明 |
|------|------|
| **不禁止，但设门槛** | 任何国家类型均可执行任何外交操作，但全女国/母系国/不同制度/不同信仰有额外成本或奖励 |
| **制度耦合** | 同制度国家好感天然+10；跨制度国家好感天然-5/月（可通过文化交流抵消） |
| **信仰耦合** | 同信仰国家好感天然+15；异教国家好感天然衰减（按08-宗教.md兼容矩阵计算） |
| **路线绑定** | 不同游戏路线解锁不同外交能力（详见第八章·路线外交） |
| **阶段解锁** | 外交能力随游戏阶段逐步解锁（详见第九章·阶段外交） |

## 二、外交结果体系

> **核心对齐**：外交结果的五种形态——掠夺、同盟、联姻、附庸、占领——详见[07-战争.md 第三章](07-战争.md)的完整定义。本节聚焦于外交视角下的结果解读，数据与07-战争.md完全一致。

### 2.1 五种外交结果速查

| 结果 | 控制深度 | 维持成本 | 收益 | 解锁条件 | 计入统一 |
|------|:--------:|---------|------|---------|:--------:|
| **掠夺** | ★ | 行军消耗+战损 | 金币10~20%+粮食10~20%+特产概率+人口2~5% | 城市Lv2+关系≤中立+≥1条故事线 | ❌ |
| **同盟** | ★★★ | 300~500金谈判费 | 共同防御+共同进攻+情报共享+贸易税率-15% | 关系≥友好(61+)+≥1条故事线 | ✅ |
| **联姻** | ★★★★ | 聘礼500~2000金 | 关系+30+获得武将+不可互攻+视野共享+贸易+20% | 关系≥友好(61+)+未婚武将+≥1条故事线 | ❌（需转化） |
| **附庸** | ★★★★ | 年贡保护+外交担保 | 年产出30%贡赋+通行权+商路权 | 多种途径（见07-战争.md 3.5节） | ✅ |
| **占领** | ★★★★★ | 驻军+同化成本 | 全部领土+资源+人口+金库50% | 全部故事线+城市Lv3+攻陷首都 | ✅ |

### 2.2 五种结果外交视角解读

#### 掠夺

| 维度 | 外交视角说明 |
|------|------|
| **外交影响** | 与目标国关系-30；威望-10；目标国可能宣战报复 |
| **限制** | 每国每季度每城最多1次；连续掠夺收益递减；冬季减半；不可与同盟/附庸共存 |
| **路线偏好** | A·君临天下（削弱手段）、E·纵横捭阖（灵活运用） |

#### 同盟

| 维度 | 外交视角说明 |
|------|------|
| **同盟收益** | ①共同防御：一方被攻击，另一方自动参战 ②共同进攻：可邀请同盟国参与己方战争 ③共享情报 ④贸易税率-15% |
| **同盟限制** | ①同盟国保留独立外交权 ②同盟国保留独立军事权（不一定响应进攻号召）③**同盟国对玩家不产生任何收益**（无贡赋、无资源、无军事调遣权） |
| **转化路径** | 同盟→联姻（满足联姻条件）；同盟→附庸（军事实力3倍+好感≥40）；同盟→占领（撕毁+宣战+征服） |

#### 联姻

| 维度 | 外交视角说明 |
|------|------|
| **联姻效果** | ①双方关系+30（永久基础加成）②获得对方一名武将 ③双方不可互相攻击 ④共享情报（视野共享）⑤贸易收入+20% ⑥**不计入统一进度**（需进一步转化） |
| **母系国家加成** | 联姻由女方主导，效果+50%（关系+45、获得2名武将、贸易+30%） |
| **全女性国家** | 需特殊剧情触发（西梁女国：子母河水外交；东女国：外部通婚协议；阿玛宗：战魁联姻） |
| **转化路径** | 联姻→同盟（联姻武将死亡时降级）；联姻→附庸（无法直接转化）；联姻→占领（主动撕毁+宣战+征服，威望-50） |

#### 附庸

| 维度 | 外交视角说明 |
|------|------|
| **附庸收益** | ①附庸国**每年**缴纳贡赋（金币+粮食+特产，合计为附庸国自身年产出×30%）②**不服从军事调遣**（不可调遣附庸国军队参战）③玩家获得附庸国的通行权和商路权 ④附庸国不可与玩家的敌人结盟 |
| **附庸限制** | ①附庸国保留内政权 ②附庸国保留独立文化/制度 ③玩家不承担附庸国治安/粮食/必需品消耗 ④玩家不可在附庸国征兵 ⑤玩家不可在附庸国掠夺 |
| **忠诚度** | 初始60；贡赋压力-2/月、驻军威慑+3/月(每100驻军)、文化影响+1/月、联姻绑定+5/月；忠诚<30→叛乱风险；忠诚<10→必定叛乱 |
| **转化路径** | 附庸→占领（宣战+征服）；附庸→同盟（忠诚≥80+主动释放）；附庸→独立（忠诚<10→叛乱） |

#### 占领

| 维度 | 外交视角说明 |
|------|------|
| **占领收益** | ①获得目标国全部领土、资源产出、人口 ②获得目标国金库50%+全部库存资源 ③获得目标国部分武将 ④获得目标国全部部落 |
| **同化成本** | 金币×人口数×制度差异系数：同族制度×0；跨族制度×0.5金/人；全女性↔普通×1金/人 |
| **占领后管理** | ①占领城邦按玩家制度运行 ②人口性别比例按同化后制度调整 ③治安初始=30 ④产出前3个月减半 |
| **不可逆** | 占领→不可退回；内部制度可通过统一决策调整（需再次支付同化成本） |

|------|---------|---------|---------|------|
| **⚔️ 军事手段** | 以武力为后盾的外交 | 威慑/征服/防御同盟 | A·君临天下 | 战争风险+国际谴责 |
| **💍 婚姻手段** | 联姻绑定利益 | 同盟巩固/附庸绑定/文化融合 | D·凤鸣昆仑 | 联姻反噬+武将损失 |

### 3.3.1 优种外交（母系/全女性国家专属）

> **优种外交**是母系/全女国家独有的一种特殊外交-生育复合机制。母系/全女国以正式外交使团名义，派遣本国优秀女性精英（女武将、女贵族、圣女祭司等）前往普通国或友好母系国，与对方国内优质男性进行交配受孕。完成受孕后，女性使节返回本国生育后代，以此获取优质基因。这既是外交手段，也是生育补充方式。

| 项目 | 说明 |
|------|------|
| **性质** | 外交手段 + 生育补充方式（复合）。参见[05-人口.md](05-人口.md) 3.1.3节·方式2 |
| **条件** | ①仅母系/全女国可发起 ②与目标国外交关系≥友好(60+) ③目标国拥有符合条件的男性武将/贵族 |
| **消耗** | 每次消耗300~500金（外交礼仪+使团费用），执行者消耗12个月（期间不可用于其他任务） |
| **执行者** | 派遣女武将/女贵族/圣女祭司执行 |
| **外交效果** | ①目标国好感+15 ②与目标国每月好感+2（持续12个月） ③与目标国贵族阶层建立联系，科技/文化交流效率+15%（持续12个月） |
| **生育效果** | ①每个成功行动+0.5%月增长率 ②新生儿基础属性+5% ③未来12个月内出生的女婴成长为武将时初始统率/武力+5 |
| **子女军团** | 若执行者为女武将，其子女成年后自动获得"优种血脉"特质（武力+3，统率+3） |
| **上限** | 最多同时与3个国家保持优种外交关系 |
| **风险** | 目标国政变或反母系势力上台→使节被扣押→好感-30+外交危机事件 |
| **冷却期** | 同一目标国完成一次后需冷却6个月方可再次发起 |
| **相关文档** | 外交增益详情见[05-人口.md](05-人口.md) 3.1.3节·方式2 |

> **设计意图**：优种外交将外交与生育深度绑定，母系/全女国在外交策略选择上多了一个维度——选择与哪个国家交好不仅是外交决策，也直接关系到后代质量和人口增长。

> 谍报系统在城市发展阶段（城市Lv3）解锁，由武将执行侦察谍报任务实现（见07-战争.md 1.3节）。

| 操作 | 条件 | 效果 | 风险 |
|------|------|------|------|
| **侦察** | 武将智力≥50 | 获取敌方城市信息（兵力/资源/武将） | 被抓获→好感-20 |
| **离间** | E路线+敌国同盟 | 敌国同盟破裂概率30~50% | 暴露→己方好感-20+宣战 |
| **煽动** | E路线+目标国稳定度<50 | 目标国叛乱概率+30% | 暴露→好感-30+国际谴责 |
| **间谍** | 好感≥30（潜伏条件） | 获取情报/破坏设施/偷取技术 | 被抓获→好感-20+间谍处死 |
| **暗杀** | E路线+高阶武将 | 消除关键武将→对方军力-20% | 失败→好感归零+宣战 |
| **策反** | E路线+敌国武将忠诚度<50 | 武将投诚→带走部分兵力 | 失败→好感-25 |
| **外交情报** | 武将执行侦察任务 | 掌握敌方弱点→外交谈判优势+20 | 被抓获→好感-20 |

### 3.6 文化手段（宗教）

| 操作 | 条件 | 效果 | 风险 |

## 四、外交引发的国家转变

> **核心设计**：外交不仅是"获取好感"的工具，更能**直接改变目标国的国家类型和政治制度**——这是外交系统的终极玩法。国家类型转变的详细规则见[04-制度.md](04-制度.md)和[05-人口.md](05-人口.md)。

### 4.1 国家类型转变

| 转变方向 | 触发方式 | 条件 | 效果 | 风险 |

## 十四、外交闭环验证

```
外交-战争闭环：
  外交好感→解锁操作→同盟/联姻/附庸→战争优势→战果→好感变化→外交升级

外交-发展闭环：
  外交贸易→经济收入→建设投入→国力增强→外交筹码增大

外交-制度闭环：
  制度匹配→好感加成→制度推荐→制度传播→制度圈扩大→加成叠加

外交-信仰闭环：
  信仰兼容→宗教交流→传教→信仰覆盖→信仰圈扩大→外交成本降低

外交-转变闭环：
  信仰传播→圣战/凤鸣觉醒→国家类型转变→制度转型→地缘格局重塑

关键平衡点：
  - 好感投入与外交回报的平衡
  - 帝国依附与独立性的取舍
  - 信仰传播与异教冲突的风险
  - 全女国/母系国外交门槛与突破成本
  - 路线选择锁定后的外交策略调整
  - 凤鸣觉醒的投入周期与转变风险
  - 六种外交手段的搭配与取舍
```
