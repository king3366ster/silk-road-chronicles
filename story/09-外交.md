## 一、外交系统总论

> **核心设计**：外交系统不是简单的"好感度→操作解锁"线性模型，而是**与国家类型、政治制度、经济制度、宗教信仰深度耦合**的立体博弈系统。不同国家类型的外交有**额外奖励和惩罚，但不禁止任何操作**——玩家可以通过特定手段突破限制，但需付出额外代价。

### 1.1 外交三维度

| 维度 | 说明 | 影响因素 |
|------|------|---------|
| **关系维度** | 好感度等级决定可执行操作的基础概率 | 国家类型/历史互动/赠礼/战争 |
| **制度维度** | 政治制度+经济制度影响外交偏好和成本 | 制度匹配度/制度冲突系数 |
| **信仰维度** | 宗教信仰影响外交深度和特殊操作 | 信仰兼容度/传教影响/异教处理 |

### 1.2 外交核心原则

| 原则 | 说明 |
|------|------|
| **不禁止，但设门槛** | 任何国家类型均可执行任何外交操作，但全女国/母系国/不同制度/不同信仰有额外成本或奖励 |
| **制度耦合** | 同制度国家好感天然+10；跨制度国家好感天然-5/月（可通过文化交流抵消） |
| **信仰耦合** | 同信仰国家好感天然+15；异教国家好感天然-3/月（可通过传教/包容抵消） |
| **路线绑定** | 不同游戏路线解锁不同外交能力（详见第八章·路线外交） |
| **阶段解锁** | 外交能力随游戏阶段逐步解锁（详见第九章·阶段外交） |

## 二、外交结果体系

> **核心设计**：外交互动的最终结果可分为四大类，每类有不同的控制深度和成本。

### 2.1 外交结果一览

| 结果 | 控制深度 | 维持成本 | 收益 | 解锁条件 | 失败风险 |
|------|:--------:|---------|------|---------|---------|
| **占领（征服）** | ★★★★★ | 驻军+同化投入 | 全部资源+人口+领土 | 军事胜利/武力威慑（A路线） | 叛乱/反抗/国际谴责 |
| **附庸** | ★★★★ | 年贡保护+外交担保 | 50%税收+军事征召+外交服从 | 好感≥30+军事压力/经济债务/册封授权 | 附庸叛离/宗主衰落 |
| **同盟（联盟）** | ★★★ | 外交维护+互惠义务 | 军事互助+贸易优惠+情报共享 | 好感≥61（友好）+制度/信仰兼容 | 利益分歧/第三方离间 |
| **臣服（朝贡、割地、赔款）** | ★★ | 定期朝贡/割地/赔款 | 保全领土+获得保护/贸易机会 | 好感≤30（被迫）或 好感≥50（主动） | 朝贡负担过重/保护失效 |

### 2.2 外交结果详细机制

#### 占领（征服）

| 维度 | 说明 |
|------|------|
| **获取方式** | 军事征服（攻占城池）→武力威慑强制占领（A路线，军力≥3倍） |
| **维持机制** | 驻军（每城≥500兵）+同化政策（见08-发展.md）+稳定度管理 |
| **收益** | 全部资源产出+人口+征兵+战略位置 |
| **风险** | ①叛乱概率=（异族人口%+异信仰%+驻军不足%）②攻占全女国→威望-15+母系国好感-20+全女国好感-30 ③过度占领→帝国警觉+干预 |
| **转化** | 占领≥12月+稳定度≥60→可转为附庸（降低维持成本） |

#### 附庸

| 维度 | 说明 |
|------|------|
| **获取方式** | ①军事压力强制附庸 ②经济债务附庸（B路线）③册封授权附庸（F路线）④文化影响附庸（C路线）⑤联姻绑定附庸（D路线） |
| **维持机制** | 年贡保护（金+粮+特产）+外交担保+定期朝觐 |
| **收益** | 50%税收+军事征召（战时可调用附庸国30%兵力）+外交服从（附庸国跟随宗主国外交立场） |
| **风险** | ①附庸叛离（好感<20+宗主国战败→叛离概率50%）②附庸独立运动（异信仰/异制度→好感-5/月）③多附庸管理成本线性增长 |
| **升级** | 附庸≥24月+同化完成→可转为占领 |

#### 同盟（联盟）

| 维度 | 说明 |
|------|------|
| **获取方式** | 好感≥61+制度/信仰兼容→同盟谈判 |
| **维持机制** | 外交维护（每+2/月）+互惠义务（军事互助+贸易优惠） |
| **收益** | 军事互助（同盟国遭攻击→可请求出兵）+贸易优惠（税率-10%）+情报共享 |
| **风险** | ①利益分歧（同盟目标不一致→好感-5/月）②第三方离间（E路线可离间敌国同盟）③同盟义务拖累（被卷入不想参与的战争） |
| **特殊** | 姐妹之盟（D路线）→母系/全女国间同盟加成×2；信仰同盟→同信仰≥3国→信仰防御+20% |

#### 臣服（朝贡、割地、赔款）

| 维度 | 说明 |
|------|------|
| **获取方式** | ①战败被迫臣服 ②主动臣服换取保护（F路线）③帝国勒索被迫臣服 |
| **维持机制** | 定期朝贡（金+粮+特产）+可能的割地/赔款 |
| **收益** | 保全领土+获得保护（宗主国出兵援助）+贸易机会 |
| **风险** | ①朝贡负担（年贡>GDP 20%→经济危机）②割地损失（领土-1→资源-10%）③赔款压力（一次性大额赔款→国库亏空）④保护失效（宗主国自身难保） |
| **解脱** | 臣服≥12月+国力恢复→可叛离（威望-10+宗主国好感归零） |

## 三、外交手段体系

> **核心设计**：六种外交手段覆盖军事、婚姻、贿赂、特务、文化、经济维度，不同路线和国家类型偏好不同手段。

### 3.1 六种外交手段总览

| 手段 | 核心逻辑 | 适用场景 | 代表路线 | 风险 |
|------|---------|---------|---------|------|
| **⚔️ 军事手段** | 以武力为后盾的外交 | 威慑/征服/防御同盟 | A·君临天下 | 战争风险+国际谴责 |
| **💍 婚姻手段** | 联姻绑定利益 | 同盟巩固/附庸绑定/文化融合 | D·凤鸣昆仑 | 联姻反噬+武将损失 |
| **💰 贿赂手段** | 以金钱/特产换取好感或让步 | 快速好感提升/收买官员/贸易优惠 | B·富甲丝路 | 人财两空+对方贪婪 |
| **🗡️ 特务手段** | 离间/煽动/间谍/暗杀 | 瓦解敌国同盟/策反武将/煽动叛乱 | E·纵横捭阖 | 暴露→好感暴减+宣战 |
| **📿 文化手段（宗教）** | 传教/文化输出/信仰拉拢 | 信仰同化/制度转型/文化圈扩张 | C·万国来朝 | 异教冲突+信仰反弹 |
| **📊 经济手段** | 商路控制/关税/制裁/封锁 | 经济附庸/贸易压制/资源垄断 | B·富甲丝路 | 商路依赖+反制裁 |

### 3.2 军事手段

| 操作 | 条件 | 效果 | 风险 |
|------|------|------|------|
| **武力威慑** | 军力≥对方2倍 | 对方外交让步概率+40% | 威望-5（霸道形象） |
| **军事胁迫** | 军力≥对方3倍+A路线 | 强制要求对方成为附庸 | 国际谴责+对方暗中反抗 |
| **联合军演** | 同盟国+好感≥70 | 好感+10+军事协同+15% | 消耗军费 |
| **雇佣兵威慑** | 支付雇佣兵费用 | 临时军力+2000→威慑效果 | 雇佣兵不可靠 |

### 3.3 婚姻手段

| 操作 | 条件 | 效果 | 风险 |
|------|------|------|------|
| **政治联姻** | 好感≥50+未婚武将 | 好感+30（永久）+贸易+15% | 武将损失+联姻反噬风险 |
| **和亲臣服** | 向帝国联姻 | 帝国好感+25+获得保护 | 独立性下降+武将损失 |
| **姐妹之盟** | D路线+母系/全女国联姻 | 联姻效果×1.5+军事协同+10% | 仅限母系/全女国 |
| **联姻策反** | E路线+敌国武将 | 策反敌国武将（见06-武将.md） | 暴露→好感-30 |
| **优种外交** 🌿 | 仅母系/全女国；好感≥60+目标国有优质男性武将/贵族 | 详见下方3.3.1节 | 详见3.3.1节 |

### 3.3.1 优种外交（母系/全女性国家专属）

> **优种外交**是母系/全女国家独有的一种特殊外交-生育复合机制。母系/全女国以正式外交使团名义，派遣本国优秀女性精英（女武将、女贵族、圣女祭司等）前往普通国或友好母系国，与对方国内优质男性进行交配受孕。完成受孕后，女性使节返回本国生育后代，以此获取优质基因。这既是外交手段，也是生育补充方式。

| 项目 | 说明 |
|------|------|
| **性质** | 外交手段 + 生育补充方式（复合）。参见[05-人口.md](05-人口.md) 3.1.3节·方式2 |
| **条件** | ①仅母系/全女国可发起 ②与目标国外交关系≥友好(60+) ③目标国拥有符合条件的男性武将/贵族 |
| **消耗** | 每次消耗300~500金（外交礼仪+使团费用），执行者消耗12个月（期间不可用于其他任务） |
| **执行者** | 派遣女武将/女贵族/圣女祭司执行 |
| **外交效果** | ①目标国好感+15 ②与目标国每月好感+2（持续12个月） ③与目标国贵族阶层建立联系，科技/文化交流效率+15%（持续12个月） |
| **生育效果** | ①每个成功行动+0.5%月增长率 ②新生儿基础属性+5% ③未来12个月内出生的女婴成长为武将时初始统率/武力+5 |
| **子女军团** | 若执行者为女武将，其子女成年后自动获得"优种血脉"特质（武力+3，统率+3） |
| **上限** | 最多同时与3个国家保持优种外交关系 |
| **风险** | 目标国政变或反母系势力上台→使节被扣押→好感-30+外交危机事件 |
| **冷却期** | 同一目标国完成一次后需冷却6个月方可再次发起 |
| **相关文档** | 外交增益详情见[05-人口.md](05-人口.md) 3.1.3节·方式2 |

> **设计意图**：优种外交将外交与生育深度绑定，母系/全女国在外交策略选择上多了一个维度——选择与哪个国家交好不仅是外交决策，也直接关系到后代质量和人口增长。这增加了母系/全女国的策略深度，同时也引入了一个外交筹码（目标国可利用优种外交使节作为人质）。
### 3.4 贿赂手段

## 四、外交引发的国家转变

> **核心设计**：外交不仅是"获取好感"的工具，更能**直接改变目标国的国家类型和政治制度**——这是外交系统的终极玩法。

### 4.1 国家类型转变

| 转变方向 | 触发方式 | 条件 | 效果 | 风险 |
|----------|---------|------|------|------|
| **普通→母系** | 凤鸣觉醒（D路线） | 圣女教覆盖>50%+女权运动≥6月+稳定度<40 | 国家类型变为母系国 | 转型期叛乱+男权反弹 |
| **普通→全女** | 凤鸣觉醒（D路线·极限） | 圣女教覆盖>70%+女性人口>80%+女权运动≥12月 | 国家类型变为全女国 | 剧烈社会震荡+男性叛乱+国际干预 |
| **母系→普通** | 制度推荐（C/F路线） | 儒教/拜火教覆盖>50%+男权运动≥6月+稳定度<40 | 国家类型变为普通国 | 转型期叛乱+女权反弹 |
| **全女→母系** | 文化渗透（C路线） | 异信仰覆盖>40%+开放政策≥12月 | 国家类型变为母系国（全女制度松动） | 保守派叛乱+神殿势力抵制 |
| **全女→普通** | 军事占领+强制同化（A路线） | 占领≥24月+强制制度推行+稳定度≥60 | 国家类型变为普通国 | 国际谴责（威望-20）+长期叛乱 |

### 4.2 政治制度转变

| 转变方式 | 触发手段 | 条件 | 效果 | 风险 |
|----------|---------|------|------|------|
| **政变** | 特务手段（煽动/策反） | 目标国武将忠诚度<40+稳定度<30 | 目标国政权更迭→亲己方势力上台 | 失败→好感归零+宣战 |
| **动荡** | 经济手段（封锁）+宗教手段（煽动） | 目标国经济<-30%+异信仰>40% | 目标国陷入动荡→3月内无法外交/军事 | 可能引发难民潮 |
| **叛乱** | 宗教手段（圣战/异教煽动） | 异信仰覆盖>50%+稳定度<25 | 目标国爆发宗教叛乱→分裂/割据 | 叛军可能不受控制 |
| **和平演变** | 文化手段（传教/文化输出） | 己方信仰覆盖>60%+好感≥70 | 目标国制度向己方靠拢→制度转型 | 演变周期长（≥12月） |
| **联姻摄政** | 婚姻手段 | 联姻+目标国统治者无嗣 | 己方武将摄政→制度影响 | 目标国贵族抵制 |

## 五、外交关系等级

### 5.1 基础关系等级

| 等级 | 好感范围 | 基础效果 | 可执行操作 |
|------|----------|----------|------------|
| **敌对** | 0-20 | 商路中断、边境冲突频发 | 宣战、掠夺、谍报 |
| **冷淡** | 21-40 | 贸易税率+20% | 朝贡、有限贸易 |
| **中立** | 41-60 | 正常贸易 | 互不侵犯、贸易协定 |
| **友好** | 61-80 | 贸易税率-10% | 军事同盟、联姻 |

```
外交-发展闭环：
  外交贸易→经济收入→建设投入→国力增强→外交筹码增大

外交-制度闭环：
  制度匹配→好感加成→制度推荐→制度传播→制度圈扩大→加成叠加

外交-信仰闭环：
  信仰兼容→宗教交流→传教→信仰覆盖→信仰圈扩大→外交成本降低

外交-转变闭环：
  信仰传播→圣战/凤鸣觉醒→国家类型转变→制度转型→地缘格局重塑

关键平衡点：
  - 好感投入与外交回报的平衡
  - 帝国依附与独立性的取舍
  - 信仰传播与异教冲突的风险
  - 全女国/母系国外交门槛与突破成本
  - 路线选择锁定后的外交策略调整
  - 凤鸣觉醒的投入周期与转变风险
  - 六种外交手段的搭配与取舍
```
