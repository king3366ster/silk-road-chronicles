## 二、五十国六大区域编排

> **类型守恒**：父系国10 + 普通国24 + 母系国10 + 全女国6 = 50；等级：大国15 / 中等国15 / 小国20。
> **分布规则**：每区域≥6国、恰有1个全女国、**至少2个大国**；北道2母系（月氏居西）、南道2母系、葱岭3母系、青藏3母系——青藏、葱岭**母系显著**；天山以北**父系国居多**（4/7）。
> **产业方向**：产业由参数表绑定（畜牧重工/轻工商业/轻工服务/重工农业/农业商业/均衡基准），与政治制度产业加成体系联动（详见[01-世界观.md](01-世界观.md)§3.4）。
> **圣水产国**（4国）：西梁女国（子母河水）、弱水国（弱水泉水）、玉河国（玉河圣水）、瑶池国（瑶池圣水）——其余母系/全女国圣水受孕所需圣水需购入（**东女、苏毗均不产圣水**）；本区域市场无圣水时，可**男奴繁殖**维持人口，或以**二级商路**赴相邻区域购入。
> **全女国起源**（六国各异，详见各表）：**同源复仇国**——斯基泰与阿玛宗同出一支被奴役的女奴部族：斯基泰以**女奴起义**夺地建国（据天山以北西缘），阿玛宗为**不堪忍受的女性集体西逃**汇聚建国（据葱岭西麓），两国相邻呼应、共叙血仇；**神话圣水系**——西梁女国为上古母神遗裔饮子母河圣水建国；**制度转型系**——东女国为母系古国「女儿当国」主动转型，优种外交+外部通婚维系；**圣泉祭司系**——弱水国为弱水圣泉祭司女团立国，守泉代代全女；**王统古国系**——苏毗女国为高原女王古国王统延续，女官女商共治。

## 四、区域自然环境与社会环境

### 4.1 ⑤ 西北·天山以北（父系居多·呼揭/乌孙所在）

| 维度 | 描述 |
|------|------|
| **水源** | 伊犁河、楚河（赤谷城畔）、玛纳斯河；伊犁河谷水源西域最丰沛 |
| **矿产** | 赤谷铁矿（楚河谷）、准噶尔西缘金铜矿（未开采） |
| **牧场** | **西域最佳牧场带**——伊犁草场、准噶尔南缘；产马占全西域六成 |
| **交通** | 匈奴南下走廊，地势开阔利骑兵；且弥天山秘道连通北道 |
| **气候** | 冬寒夏凉，白灾（雪灾）为最大天灾 |

**社会环境**：父系国居多（4/7：呼揭、乌孙、赤谷、且弥），收继婚与游牧军事化传统；斯基泰全女部众（女奴起义建国）孤悬草原西缘，与葱岭阿玛宗同源呼应（同源复仇国）；郁立师、单桓为缓冲小邦。

**挑战与冲突**：白灾周期（雪灾灭畜→南下掠夺）；乌孙—车师争天山门户；斯基泰建国血仇使全女与父系阵营结构性对立；匈奴勒索贡赋。

**外部势力**：匈奴控制最强区——赤谷、呼揭联乌孙抗匈为生存主线。

### 4.2 ④ 东北·天山东部（汉朝—匈奴拉锯前沿）

| 维度 | 描述 |
|------|------|
| **水源** | 坎儿井地下水系（车师/高昌）、巴里坤湖、伊吾河谷泉流 |
| **矿产** | 煤炭露头、铁砂（次要） |
| **牧场** | 巴里坤草原（蒲类） |
| **交通** | **丝路咽喉**——车师扼天山南北两口；伊吾连河西走廊（汉朝入西域第一站） |
| **气候** | 极端干燥炎热（吐鲁番海平面以下），绿洲全赖地下水 |

**社会环境**：农耕商贸复合，汉朝移民与屯田影响最深；弱水全女国（圣泉祭司女团立国，代代全女）邻近北道母系诸国（月氏/焉耆），信仰互通。

**挑战与冲突**：汉匈拉锯（车师两度易手，历史车师之乱）；坎儿井水权即政治；父系车师封建制与商贸城邦的制度摩擦。

**外部势力**：汉朝设伊吾庐屯田校尉；匈奴以蒲类为马场跳板；佛教自贵霜经此东传（高昌佛寺）。

### 4.3 ① 中心·北道（绿洲城邦链·贸易心脏）

| 维度 | 描述 |
|------|------|
| **水源** | 孔雀河、渭干河、阿克苏河绿洲链；博斯腾湖（西域最大淡水湖） |
| **矿产** | 龟兹铜厂山铁矿、危须河谷铁矿 |
| **牧场** | 山麓有限牧场 |
| **交通** | **丝路北道主干**——绿洲连珠，补给最便利；疏勒汇南北两道 |
| **气候** | 干旱绿洲气候，灌溉农业精细 |

**社会环境**：城邦自治与商贸市民阶层发达；西段形成母系/全女连续带（西梁—月氏—焉耆），东段为城邦市政普通国；乌垒都护府使北道东段为汉朝行政核心。

**挑战与冲突**：孔雀河上下游争水（尉犁vs焉耆）；龟兹—姑墨盐铁利权；西梁全女国与疏勒商贸圈的通商—通婚博弈；匈奴骑兵自天山东段劫掠商队。

**外部势力**：汉朝都护府（焉耆乌垒城）直接行政；贵霜佛教东传（龟兹译经）；匈奴威胁北道东端。

### 4.4 ② 中心·南道（玉石之国·沙化前沿）

| 维度 | 描述 |
|------|------|
| **水源** | 玉龙喀什河、克里雅河、车尔臣河；尼雅河沙化（精绝危机）、罗布泊萎缩（鄯善危机） |
| **矿产** | 昆仑玉脉全境（于阗籽料最高） |
| **牧场** | 昆仑高山牧场有限；骆驼养殖为特色运力 |
| **交通** | 丝路南道主干——绿洲间距大，依赖驼队 |
| **气候** | 极端干旱，**沙漠化为全域最大生存威胁** |

**社会环境**：城邦自治+佛教信仰圈；精绝（尼雅女神崇拜）、扜弥两个母系城邦居中段；东女全女国扼南道东端与青藏通道交汇；且末父系边城为南道唯一父系数点。

**挑战与冲突**：沙漠侵蚀绿洲（精绝/鄯善存亡危机）；玉石利权争夺（于阗—皮山—莎车链）；鄯善为汉匈争夺焦点；东女国通商—通婚博弈；且末军事化边城与母系邻邦的紧张。

**外部势力**：鄯善为汉朝南道第一站；贵霜佛教东传至于阗/精绝；贸易依赖使南道诸国谨慎平衡。

### 4.5 ⑤ 西南·葱岭（母系显著·高原天险）

| 维度 | 描述 |
|------|------|
| **水源** | 帕米尔冰川融水、玉河上游、依耐盐湖 |
| **矿产** | 青玉矿脉（青鸾）、籽料（玉河）、帕米尔铁矿（无雷） |
| **牧场** | 高原牧场2000~3500米；大宛费尔干纳农牧两旺 |
| **交通** | **丝路西端天险**——蒲犁关、捐毒山口控扼；冬季封冻隔绝 |
| **气候** | 高寒（腹地3500米+），费尔干纳温润 |

**社会环境**：母系氏族公社文化圈（青鸾/玉河/灵山三女邦相连，母系显著）；大宛商贸城邦为区内最大普通国；阿玛宗猎头女骑（斯基泰同源·同源复仇国）游掠传统。

**挑战与冲突**：高原补给漫长（远征折损+40%）；山口封冻季贸易中断；大宛汗血马引来汉匈觊觎（历史大宛之战）；封建奴隶制（无雷）逃奴线指向母系邻国；阿玛宗游掠与商路的摩擦。

**外部势力**：贵霜自南侧威压（小国纳贡避战）；帕提亚商路垄断西端；汉朝远征军曾至大宛。

### 4.6 ⑥ 东南·青藏（母系显著·高原圣域）

| 维度 | 描述 |
|------|------|
| **水源** | 昆仑东端冰川、高原湖泊（瑶池）、河西走廊疏勒河绿洲带 |
| **矿产** | 昆仑东端玉矿、盐湖、藏北金矿 |
| **牧场** | 高原牧场广而承载力低；白兰/发羌牦牛畜群 |
| **交通** | 昆仑山口通道（婼羌—南道）、河西走廊（汉朝丝路本土段） |
| **气候** | 高原缺氧，冬季极端；天然屏障使外敌难入 |

**社会环境**：母系氏族联盟文化圈（白兰女国联盟、瑶池西王母信仰、玄女兵法部族——母系显著）；象雄为高原苯教文明古国；苏毗全女商队纵横高原；婼羌扼昆仑山口衔接南道（与西羌特殊贸易）；发羌为羌人父系部落；唐旄扼高原古道枢纽。

**挑战与冲突**：高原缺氧补给难（屏障双向生效）；羌人部落（发羌父系/婼羌）与母系城邦互补—摩擦共生；象雄与唐旄争高原古道贸易正统。

**外部势力**：西羌联盟自东北渗透（与发羌同源联动）；汉朝控制河西走廊；苏毗商队联通南道与高原转口贸易。

### 6.3 四级商路（贸易权限）

| 商路等级 | 贸易权限 | 建立成本（见[04-政治制度.md](04-政治制度.md)§6.3） |
|:--------:|----------|--------------------------------------------------|
| **一级商路** | 本区域核心市场+小市场：交易**区域特产**及**区域内国家特产** | 200金+2马匹 |
| **二级商路** | ＋**相邻区域**：交易相邻区域特产及对应国家特产 | 500金+5马匹+3骆驼 |
| **三级商路** | ＋**全部西域区域**：交易全部区域特产 | 1000金+10马+5骆驼+10丝绸 |
| **四级商路** | ＋**外部势力**：交易势力特产（汉朝、匈奴、贵霜、帕提亚、罗马、西羌） | 3000金+20马+10骆驼+50丝绸+20玉石 |

- **奴隶市场准入随商路等级**：一级=本区域奴市；二级=相邻区域奴市；三级=全部区域奴市（四级另享势力雇佣兵渠道）。
- **区域相邻关系**：天山以北↔天山东部/北道/葱岭（伊犁河谷西接葱岭北麓）；天山东部↔天山以北/北道/南道（罗布泊）/青藏（河西走廊南）；北道↔天山以北/天山东部/南道/葱岭（西端）；南道↔北道/葱岭/青藏（昆仑山口）/天东部（罗布泊东北）；葱岭↔北道/南道；青藏↔南道/天山东部。
- **商路等级联动**：B·富甲丝路「市场操纵（商路Lv4+）」判定与「经济控制」定义见[01-世界观.md](01-世界观.md)§2.4；商路收入公式与建设成本明细见[04-政治制度.md](04-政治制度.md)§6.3；**全域生产-消耗供需总账**（18种区域特产+国家特产+势力特产逐品核算）见[04-政治制度.md](04-政治制度.md)§八。
