## 一、军事制度总览（3+1体系）

| 制度 | 核心机制 | 适用场景 | 兵力上限 | 消耗模式 |
|------|----------|----------|:--------:|----------|
| **① 征兵制** ⚔️ | 公民征召（临时Lv0）→职业常备（Lv1~Lv5两级） | 大规模战争、开启国家战争系统 | 总人口×20%（含常备） | 消耗公民+兵器；常备另耗粮金 |
| **② 雇佣兵制** 💰 | 按月付费，不消耗本国人口 | 精锐补充、转型过渡 | ≤本国总兵力80% | 仅金钱（10~18金/人/月） |
| **③ 部落/民兵制** 🏹 | 敌攻入内城时触发，公民临时受编Lv0 | 仅城防自卫 | 符合条件公民×50% | 仅战时，战后自动解散 |
| **④ 贵族私兵制** 👑 | 玩家专属私人武装（阶段六解锁） | 剧情推进、政变保障 | 受玩家身份等级限制 | 玩家私库支出 |

### 1.1 阶段解锁

| 阶段 | 可用军事制度 | 玩家专属解锁 |
|------|-------------|-------------|
| 一 | 民兵制 | 武器/装备/道具基础功能 |
| 二 | +征兵制（临时征召） | 幕僚招募（初始1名） |
| 三 | +征兵制（职业常备） | 幕僚→武将/文官转化，开启国家战争系统 |
| 四 | +雇佣兵制 | 武将/文官体系成熟 |
| 五 | 全部3种 | 小型近卫军（500人雏形） |
| 六 | +贵族私兵制 | 近卫军成建制（3,000人） |
| 七 | 全部3+1种 | 后宫系统、禁卫军（5,000人） |

## 二、三大制度详解

### 2.1 征兵制（两级体系）

**一级：临时征召（公民兵）**——触发：战争状态+兵力<常备上限80%+稳定≥30；即时完成；初始Lv0；⚠️消耗公民、满意度-5/次、兵器（步兵×2/骑兵×1/弓骑×1）；战后可解散（满意度+3）。

**二级：职业常备**——解锁：城市Lv3+宣战能力+≥1条对外故事线；兵力上限总人口×10~15%；招募5回合；消耗20金招募+10金装备+2粮1金/人/月；每12月+1级（上限Lv5）；解散遣散费10金/人。

**征兵国家差异**：父系只征男兵（10:0）｜普通男兵为主+少量女兵（≤30%）｜母系男女混编（推荐5:5）｜全女全女兵——详见§八国家类型军事特色。

### 2.2 雇佣兵制

| 维度 | 规则 |
|------|------|
| 触发 | 城市Lv2+经奴隶市场+资金充足 |
| 上限 | ≤本国总兵力80%（硬性） |
| 价格 | 10~18金/人/月（8种雇佣兵详见§三.5） |
| 期限 | 最少3个月；战斗中解约该回合防御-20% |
| 忠诚 | 固定50不可提升；欠薪叛变+10%/月 |
| 性别 | **不占性别名额、不入人口统计**：全女国可雇男性、父系国可雇女性（均不可归化，解约即离境） |
| 同化 | 雇佣≥12月+城市Lv3+月费×12 → 转为对应Lv2兵种（忠诚60） |

### 2.3 部落/民兵制

敌军攻入**内城**时触发事件，玩家决定是否征召：16~50岁非军人公民×50%；初始Lv0（战力≈常备40%）；满意度-3/次；战后自动解散；守城成功满意度+10、失败-20。❌不可用于对外作战。

### 2.4 政治—军事制度兼容矩阵

> **基础准则**：军事制度与政治制度存在适配关系——**最佳适配**（战力+10%，军费-10%）/**兼容**（正常运行）/**排斥**（战力-20%，军费+20%）。

| 政治制度 ↓ | 征兵制（职业常备） | 雇佣兵制 | 部落/民兵制 |
|-------------|:------------------:|:--------:|:-----------:|
| **君主专政制** | ✅ **最佳适配** | ✅ 兼容 | ❌ 排斥 |
| **部落酋长制** | ❌ 排斥 | ✅ 兼容 | ✅ **最佳适配** |
| **贵族议政制** | ✅ **最佳适配** | ✅ 兼容 | ✅ 兼容 |
| **城邦市政制** | ❌ 排斥 | ✅ 兼容 | ✅ **最佳适配** |
| **宗教领袖制** | ✅ 兼容 | ✅ 兼容 | ✅ 兼容 |
| **封建奴隶制** | ❌ 排斥 | ✅ 兼容 | ✅ 兼容 |
| **民主共和制** | ✅ **最佳适配（公民兵）** | ✅ 兼容 | ✅ **最佳适配** |

**排斥组合说明**：

| 排斥组合 | 原因 |
|----------|------|
| 君主专政制 + 部落/民兵制 | 君主不容民间武装，视为王权威胁 |
| 部落酋长制 + 征兵制（职业常备） | 部落自治无法维持中央常备军财政 |
| 城邦市政制 + 征兵制（临时征召） | 市民不愿承担长期兵役，倾向专业军队 |
| 封建奴隶制 + 雇佣兵制/征兵制（常备） | 领主各有农奴兵与领地自治，排斥市场化雇佣与中央常备 |

**最佳适配收益示例**：君主专政+职业常备（指挥效率+10%）；部落酋长+民兵（全民皆兵传统，补给自足）；城邦市政+民兵（保卫家园，城防+15%）；宗教领袖制+职业常备（宗教狂热，战力+15%）；民主共和+公民兵（公民自组织，士气+10%）。

#### 2.4.1 军事制度转换触发方式

| 方式 | 说明 | 典型场景 |
|------|------|----------|
| **① 军事改革** | 玩家主动发起 | 民兵→征兵制（加强军力）；征兵→雇佣（经济支持） |
| **② 战争教训** | 重大胜败后反思 | 被游牧击败→加强城防民兵；征服胜利→扩大常备军 |
| **③ 产业变化** | 产业方向变化推动 | 商业发达→雇佣兵制；农业充裕→征兵制 |
| **④ 外部威胁** | 强敌压境 | 帝国级威胁→全民动员征兵制 |

**转换条件表**：

| 目标制度 | 前置条件 | 消耗 |
|----------|----------|:----:|
| 征兵制 | 总人口≥5000+粮储≥6月+户籍登记率≥80% | 1000金 |
| 雇佣兵制 | 金库≥3000金+佣兵组织联系（定金≥30%） | 2000金 |
| 部落/民兵制 | 民兵凝聚力≥70+城防设施完善 | 500金 |

**战争教训触发**：一场战役损失≥25%兵力→强化征兵制；首都/重镇被攻破→民兵制城防觉醒；拖欠军饷>3月（雇佣兵背叛）→转征兵制。

**外部威胁触发**：汉朝/匈奴宣战→征兵制全民动员；≥3国同时宣战→雇佣兵制多线应对；边境持续劫掠→征兵制快速反应部队。

#### 2.4.2 军事改革事件链

| 事件名称 | 流程 | 完成效果 |
|----------|------|----------|
| **整军经武**（民兵→征兵） | 宣布改革→旧军遣散（500金）→招募新军（2000金）→训练期6月（战力-30%） | 战力+20%，军费+50% |
| **雇佣兵本土化**（雇佣→征兵） | 合同到期→优秀佣兵转公民兵→本地补充→训练期 | 军费-15%，守土意愿+10% |
| **全民武装动员**（征兵→民兵） | 全民登记→配发武器（1500金）→基础训练→编入城防 | 城防+30%，对外战力-10% |
| **金库换安全**（征兵→雇佣） | 财政评估→签佣兵合同（2000金）→替换旧军 | 人口不消耗，外交灵活性+10% |

#### 2.4.3 军事制度冲突事件

| 冲突类型 | 触发条件 | 效果 | 解决方案 |
|----------|----------|------|----------|
| **雇佣兵叛乱** | 拖欠军饷>3月 | 雇佣兵叛变攻城 | 补薪+违约金（3000金）/ 武力镇压 |
| **民兵厌战** | 民兵制下战争>12月 | 士气-20，逃亡+10%/月 | 转征兵制（3000金）/ 谈判停战 |
| **私兵割据** | 征兵制下贵族私兵并存 | 管理成本+30% | 强制解散（贵族满意度-30）/ 允许并存（稳定-5/月） |

#### 2.4.4 强制同化期间的转换限制

| 情况 | 规则 |
|------|------|
| 已选择强制同化 | 军事制度不可转换（稳定优先） |
| 已完成强制同化 | 可转换，但须与最终政治制度兼容（排斥组合禁选） |
| 双轨并行期间 | 可转换，但需分别管理不同制度的军队（管理成本+30%） |

## 四、国家类型与各国军事特色

| 类型 | 特色 |
|------|------|
| 父系国 | 全男兵10:0；出现女兵稳定-20/月强制退役 |
| 普通国 | 男兵为主；女兵>30%触发"男兵非议"（稳定-5） |
| 母系国 | 混编5:5推荐，女兵士气+15%；男兵>70%触发"女兵请愿"；女武将统帅上限+1，男武将不可任最高统帅 |
| 全女国 | 全女兵+20%；兵力恢复-25%（最大弱点）；攻占全女国者威望-15 |

**各国特色（示例）**：西梁守城攻+20%防+15%｜苏毗山地防+25%商路军费-5%｜阿玛宗掠夺×2俘虏+15%｜斯基泰弓骑射程+1齐射+25%｜弱水敌渡河攻-30%｜瑶池昆仑卫山地防+35%｜月氏月骑移+2撤退损-40%｜玄女阵法+10%经验+25%｜赤谷赤甲卫防+40%｜灵山药女卫每回合恢复邻军15%｜玉河玉卫极弱型。母系联动：全女-母系纽带攻防+10%。

### 4.1 斯基泰/阿玛宗木武器体系（专属）

- **生产**：两国只需**伐木取材**（木材2→1，制弓坊/制盾坊，无需铁矿/铁匠铺/兵器坊）即可量产**斯基泰弓/阿玛宗盾**（详见[04-政治制度.md](04-政治制度.md)§4.3/§5.2）
- **战场使用**：替代普通国家兵种武器装备部队（省去兵器消耗与铁料依赖），**对男性士兵+20%战力加成**
- **【同源复仇】加成边界**：对**父系国**开战→掠夺/俘虏/歼灭男性**+20%**；对**普通/母系/全女国开战无任何加成**
