## 一、概述

国家类型转换是指西域五十国在**普通国家、母系国家、全女性国家**三大类型之间的制度性转型。不同类型的转型触发条件、事件流程、影响范围各不相同。本文档集中论述各类**国家类型转换触发事件**的详细规则与剧情节点。

### 1.1 转型路径总览

```
   普通国家 ──[凤鸣觉醒]──→ 母系国家 ──[女儿当国]──→ 全女性国家
       ↑                       │                         │
       └───────[父权复辟]──────┘                         │
                                 ↑                        │
                                 └──────[凤归母巢]────────┘

   父权极端 ⛓️ ──[父权崩塌]──→ 普通国家(5:5) ──[凤鸣觉醒]──→ 母系国家(3:7)
       ↑                                                   │
       └────[征战屠杀+掠夺女奴]←── 普通国家 ───────────────┘
                                (通过战争改变性别比)

   注意：父权极端→普通→母系 = 两步走（先父权崩塌恢复普通，再凤鸣觉醒转母系）
         普通→父权极端 = 通过征战屠杀男性+掠夺女奴改变公民性别比至7:3
         全女性→普通 = 不可能（信仰崩溃）
```

### 1.2 四大国家类型核心参数

| 维度 | 普通国家（24国） | 父权极端（12国）⛓️ | 母系国家（8国） | 全女性国家（6国） |
|------|-----------------|-------------------|----------------|------------------|
| **人口构成** | 公民5:5 | 公民7:3，奴隶3:7 | 公民3:7 | 0:100 |
| **统治者性别** | 男性或女性均可 | **必须为男性** | 必须为女性 | 必须为女性 |
| **政治制度** | 6种标准制 | 6种标准制（但女性全无参政权） | 6种母系变体 | 6种全女变体 |
| **兵源** | 仅男兵 | 仅男兵（女性不得参军） | 男兵:女兵=8:2~6:4 | 仅女兵（战力+10%） |
| **转型难度** | ★★★☆☆ | ★★★★★（转型阻力最大） | ★★★★☆ | ★★★★★ |

## 二、主动转型事件（类型二）

> 当人口性别比例发生变化，社会内部女权力量抬头或男权复辟时触发的主动制度转型。与强制同化（类型一）完全独立，可并行发生。

### 2.1 凤鸣觉醒（普通→母系）

> 普通国家因女性人口比例持续超过阈值，女权力量抬头，触发制度向母系方向转型。

#### 触发条件

| 条件项 | 要求 |
|--------|------|
| **人口条件** | 势力全部公民女性比例≥55%（普通国基准5:5，女性需超半数），连续36回合（1年） |
| **稳定度** | 稳定度≥50 |
| **外交接触** | 与至少1个母系或全女国家有外交接触/商路往来 |
| **阶段限制** | 阶段四起可触发 |
| **触发频率** | 每年至多1次 |

#### 触发事件链

| 事件节点 | 回合 | 内容 | 玩家选择 |
|----------|------|------|----------|
| **① 女权思潮** | 女性比例≥52%时首次提示 | 城邦中出现女权思潮运动，女性贵族要求在议事会中获得更多席位 | ①压制（稳定度-10，女性满意度-15）②倾听（女性满意度+10） |
| **② 女性集会** | 女性比例≥53%时 | 女性市民在广场集会，要求政治权利平等 | ①武力驱散（稳定度-15，女性满意度-20）②和平对话（女性满意度+10） |
| **③ 女权领袖出现** | 女性比例≥55%时 | 一位具有魅力的女性领袖出现，领导女权运动 | ①逮捕领袖（女性满意度-25，稳定度+5）②支持领袖（女性满意度+20，稳定度-5） |
| **④ 转型抉择** | 女性比例≥55%持续36回合后 | 女权运动达到高潮，要求正式实行母系制度 | **【接受转型】或【拒绝转型】** |

#### 接受转型效果

| 效果项 | 详情 |
|--------|------|
| **政治制度** | 转为对应母系政治制度变体（如君主专政制→母系君主专政制） |
| **经济制度** | 不变（可后续转型） |
| **人口调整** | 男性公民可遣散（补偿金200金/千人）或保留公民身份但不可为统治者 |
| **军队调整** | 男兵可遣散（补偿金）或转业；女兵可从精锐卫队中征召 |
| **稳定度** | →100 |
| **外交影响** | 与全女国/母系国外交好感自动+15；与普通国家好感-10 |
| **路线解锁** | 解锁D线·凤鸣昆仑（若之前未解锁） |

#### 拒绝转型效果

| 效果项 | 详情 |
|--------|------|
| **稳定度** | -20（女权运动镇压） |
| **女性满意度** | -30（持续6个月） |
| **叛乱风险** | +10%/月，持续12个月 |
| **再次触发** | 条件持续满足时，12个月后再次触发判定 |

> **设计意图**：凤鸣觉醒是社会人口结构变化驱动的自然转型，与军事征服路线独立。普通国女性玩家可借此事件平稳过渡到母系统治；男性玩家若想保持男权统治，需持续维持男性人口优势。

### 2.2 女儿当国（母系→全女）

> 母系国家男性人口持续减少至接近零时，社会向全女性化转型。

#### 触发条件

| 条件项 | 要求 |
|--------|------|
| **人口条件** | 势力全部公民男性比例≤15%（接近全女国0%标准），连续36回合（1年） |
| **稳定度** | 稳定度≥50 |
| **外交接触** | 与至少1个全女国家有外交接触 |
| **阶段限制** | 阶段四起可触发 |
| **触发频率** | 每年至多1次 |

#### 触发事件链

| 事件节点 | 内容 | 玩家选择 |
|----------|------|----------|
| **① 男性减少** | 城邦中适龄男性数量持续下降，女性承担更多社会职能 | ①鼓励男性生育（人口政策调整，花费500金）②顺应自然趋势（不干预） |
| **② 女神崇拜兴起** | 全女国宗教文化传入，女神崇拜在女性中流行 | ①允许传播（宗教多元化，稳定度-5）②禁止传播（宗教保守，女性满意度-10） |
| **③ 全女呼声** | 激进派女性贵族提出驱逐全部男性的动议 | ①支持动议（男性满意度-20，女性满意度+15）②否决动议（女性满意度-10） |
| **④ 转型抉择** | 男性比例≤15%持续36回合后，全女转型条件成熟 | **【接受转型】或【拒绝转型】** |

#### 接受转型效果

| 效果项 | 详情 |
|--------|------|
| **政治制度** | 转为对应全女政治制度变体（如母系君主专政制→全女君主专政制） |
| **经济制度** | 不变（可后续转型） |
| **人口调整** | 男性公民可遣散（补偿金200金/千人）或自愿外迁至邻国；**不涉及强制转奴隶** |
| **军队调整** | 男兵可遣散（补偿金）；军队转为全部女兵 |
| **稳定度** | →100 |
| **外交影响** | 与全女国外交好感自动+25；与普通国家好感-15 |
| **特殊规则** | 若存在男性玩家角色，触发「唯一合法男性」事件（详见11-玩家角色.md） |

#### 拒绝转型效果

| 效果项 | 详情 |
|--------|------|
| **稳定度** | -15 |
| **女性满意度** | -20（持续6个月） |
| **激进派独立风险** | 激进派女性贵族可能发动分裂，部分城邦以全女国身份独立 |
| **再次触发** | 条件持续满足时，12个月后再次触发判定 |

### 2.3 父权崩塌 ⛓️（父权极端→普通·暴力革命）

> 父权极端国家因女性长期受压迫，在外部力量催化下爆发系统性暴力革命，推翻极端父权制度，恢复普通国家制度（公民男女比5:5）。**与凤鸣觉醒的和平演变不同，父权崩塌是暴力革命。转型后为普通国，可后续通过凤鸣觉醒进一步转为母系国。**

#### 触发条件

| 条件项 | 要求 |
|--------|------|
| **人口条件** | 女性满意度<25（长期压抑），连续24回合以上 |
| **稳定度** | 稳定度<30（社会动荡期） |
| **外部介入** | 与至少1个母系或全女国家有外交接触/商路往来，且该国外交影响力≥40 |
| **催化剂事件** | 需触发以下任一：①女性反抗事件（如集体逃亡/抗税）②外部女权思想传入③母系/全女国间谍渗透 |
| **阶段限制** | 阶段四起可触发 |
| **触发频率** | 仅1次（成功转型后锁定） |

#### 触发事件链

| 事件节点 | 内容 | 玩家选择 |
|----------|------|----------|
| **① 暗流涌动** | 地下女性组织秘密串联，受母系/全女国传单和书籍影响 | ①加强监控（稳定度+5，女性满意度-5）②放任（女性组织壮大，稳定度-5） |
| **② 公开反抗** | 女性集体抗税/罢工/拒绝生育 | ①武力镇压（稳定度+10短期，女性满意度-15）②谈判（女性满意度+10，保守派-10） |
| **③ 外部介入** | 母系/全女国公开声援女性反抗者，提供资金和武器 | ①封锁边境（与母系/全女国关系-30）②抗议但放任（关系-10） |
| **④ 革命爆发** | 女性武装起义，配合外部势力介入，父权政权动摇 | **【支持革命→父权崩塌】或【镇压→内战持续】** |

#### 接受转型效果（父权崩塌→普通国）

| 效果项 | 详情 |
|--------|------|
| **国家类型** | 父权极端→**普通国家**（公民男女比由7:3恢复为5:5） |
| **政治制度** | 废除极端父权法律；恢复女性基本公民权（参政权逐步开放，需6个月过渡期） |
| **经济制度** | 不变（但需重新分配土地和财产权，废除女奴无偿劳役制度） |
| **人口调整** | 男性特权阶层部分逃亡/处决；女奴部分释放为公民；人口比例逐步调整为5:5 |
| **军队调整** | 原有男兵遣散30%，允许女性有限参军（不得超过总兵力的10%） |
| **稳定度** | 革命期间降至20，转型后恢复至60 |
| **经济代价** | 革命造成经济产出-40%持续6个月，重建需2000~4000金 |
| **外交影响** | 与母系/全女国外交好感+20（改革形象）；与父权极端国好感-20（威胁形象） |
| **后续路线** | 解锁后续转型：**父权崩塌→普通国→[凤鸣觉醒]→母系国** |

#### 拒绝转型效果（镇压）

| 效果项 | 详情 |
|--------|------|
| **稳定度** | -30（大规模镇压） |
| **人口损失** | 女性人口-10%~20%（屠杀/逃亡） |
| **女性满意度** | -40（持续12个月） |
| **外交影响** | 与母系/全女国关系-40（人道主义谴责） |
| **再次触发** | 条件持续满足时，6个月后再次触发判定（革命可能卷土重来） |

### 2.4 征战极端化 ⚔️（普通→父权极端·战争催化）

> 普通国家通过持续对外征战，大量屠杀敌国男性公民、掠夺女性为奴，导致国内公民性别比严重失衡（男性比例上升至70%以上），父权势力借机强化统治，最终制度向父权极端转型。

#### 触发条件

| 条件项 | 要求 |
|--------|------|
| **战争条件** | 连续征战并屠杀男性≥3次（每次屠戮男性人口>500），且掠夺女奴总数>公民女性人口的20% |
| **人口条件** | 男性公民比例>60%（因战争男性死亡少+女奴转化为公民），持续12回合以上 |
| **政治条件** | 稳定度≥50（战争胜利带来威望），男权保守派势力影响力≥60 |
| **催化剂事件** | ①保守派提出"强化男权法案" ②外部父权极端国思想传入 ③女性反抗被镇压后保守派借机夺权 |
| **阶段限制** | 阶段三起可触发 |
| **触发频率** | 条件满足时可触发，转型后锁定（除非父权崩塌） |

#### 触发事件链

| 事件节点 | 内容 | 玩家选择 |
|----------|------|----------|
| **① 战争红利** | 连年征战带来大量女奴和战利品，男性地位空前上升 | ①分配女奴给有功将士（男性满意度+15，女性满意度-10）②释放部分女奴为公民（女性满意度+10，保守派-10） |
| **② 性别失衡** | 男多女少导致婚姻市场紧张，女性被进一步物化 | ①管制女奴买卖（保守派-15，稳定度+5）②放任市场调节（女奴价格飙升，保守派+10） |
| **③ 保守派法案** | 保守派提出《男性特权法案》：限制女性财产权、继承权、教育权 | ①签署法案（→父权极端，稳定度+20短期，女性满意度-25）②否决法案（保守派影响力-20，可能触发政变） |
| **④ 制度锁定** | 法案通过后，父权极端制度正式确立 | **【接受→正式转为父权极端国】或【抵抗→内战】** |

#### 接受转型效果（普通→父权极端）

| 效果项 | 详情 |
|--------|------|
| **国家类型** | 普通→**父权极端**（公民男女比由5:5变为7:3，奴隶比由任意变为3:7女奴占多） |
| **政治制度** | 通过《男性特权法案》，女性丧失参政/继承/财产权；议会/朝堂只为男性开放 |
| **经济制度** | 不变（但女奴被全面纳入无偿劳役体系，农业/手工业产出因女奴增加短期+15%） |
| **人口调整** | 女奴大量增加（俘虏+买卖），奴隶男女比调整为3:7；舞女/侍妾占比可达奴隶人口的30% |
| **军事调整** | 全男兵制强化，女性彻底被排除出军事领域；士兵可从女奴后代中征召（补充兵源） |
| **稳定度** | →80（短期，男性权威得到法律保障），但女性满意度降至20以下 |
| **外交影响** | 与父权极端国好感+15；与母系/全女国好感-20（制度对立恶化） |
| **后续路线** | 解锁父权崩塌路线（唯一回归路径） |

#### 拒绝转型效果（拒绝法案）

| 效果项 | 详情 |
|--------|------|
| **稳定度** | -20（保守派反弹） |
| **保守派影响力** | -20（否决法案后受压制） |
| **政变风险** | 保守派可能发动军事政变（概率30%~50%） |
| **再次触发** | 条件持续满足时，12个月后再次触发判定 |

## 三、强制同化中的自身调整（类型一·附属）

> 当征服国选择强制同化时，自身可能先因接触外界而发生制度转变。详见[04-制度.md](04-制度.md)第6.2节。此处仅列出触发条件摘要。

### 3.1 自身调整触发条件汇总

| 转型事件 | 方向 | 触发条件 | 属于强制同化第一步 |
|----------|------|----------|:------------------:|
| **🌸 凤鸣觉醒** | 普通→母系 | 与全女/母系国接触 + 稳定度≥70 + 女性公民比例>70%持续36回合 | ✅ |
| **🔄 父权复辟** | 母系→普通 | 与普通国接触并受影响 + 稳定度≥70 | ✅ |
| **🔥 女儿当国** | 母系→全女 | 与全女国接触 + 稳定度≥70 + 男性公民比例<10%持续36回合 | ✅ |
| **💧 凤归母巢** | 全女→母系 | 与母系/普通国接触 + 稳定度≥70 | ✅ |

### 3.2 与主动转型的差异

| 维度 | 强制同化（自身调整） | 主动转型（类型二） |
|------|--------------------|------------------|
| **触发前提** | 必须先选择强制同化 | 与强制同化选择无关 |
| **人口阈值** | 更严格（女性比例>60%而非≥55%） | 较宽松（女性比例≥55%） |
| **调整性质** | 作为同化流程的一部分，后续还有激进阶段 | 独立发生，仅温和调整 |
| **锁定效果** | 完成强制同化后自身制度永久锁定 | 不锁定，可再次转型 |

---

## 四、叛乱引发的被动转型（类型三）

> 因性别比例失衡或外国渗透引发的叛乱，可能导致城邦以另一类型的国家身份独立。

### 4.1 男权反扑叛乱

| 维度 | 说明 |
|------|------|
| **触发情景** | 母系国或全女国内部因男性比例升高，或受普通国家渗透，男性势力发动叛乱 |
| **转型方向** | 全女/母系→普通（独立） |
| **触发条件** | ①母系国：男性公民比例>40%+稳定度<30持续3回合；②全女国：引入男性未及时处置 |
| **独立后果** | 叛乱的城邦以普通国身份独立，脱离玩家控制，不可逆 |
| **平叛方式** | 详见[04-制度.md](04-制度.md)第6.4.3节 |

### 4.2 渗透引发叛变

| 维度 | 说明 |
|------|------|
| **触发情景** | 外国势力（普通国为主）向母系/全女城邦渗透，煽动内部反对派 |
| **转型方向** | 全女/母系→普通（加入渗透国） |
| **典型事件** | 「外来商旅的阴谋」「传教士的秘密使命」「敌国间谍网」 |
| **预防手段** | 维持稳定度≥50，定期清理外国间谍，限制外来人员活动范围 |

## 五、阶段相关国家转型事件索引

以下为各游戏阶段可触发的国家转型事件汇总，按阶段排序：

| 游戏阶段 | 可触发事件 | 说明 |
|----------|-----------|------|
| **阶段一** | 无 | 新手保护期，无国家转型事件 |
| **阶段二** | 无 | 新手保护期，无国家转型事件 |
| **阶段三** | 男权反扑叛乱（被动） | 保护期结束，可能因前期布局引发叛乱 |
| **阶段四** | 凤鸣觉醒、女儿当国、**父权崩塌**（主动+强制同化自身调整） | 制度选择期，转型事件密集 |
| **阶段五** | 凤鸣觉醒、女儿当国、父权复辟、凤归母巢、**父权崩塌** | 强制同化最终决定期，转型达到高潮 |
| **阶段六** | 凤鸣觉醒、女儿当国、**父权崩塌**（延续触发） | 势力扩张期，转型影响范围扩大至所有被占领国 |
| **阶段七** | 外部势力干预转型 | 外部势力正式参战，可能通过外交/军事手段强制改变国家类型 |

## 六、事件触发判定流程

```
每回合判定开始
    │
    ├── 是否处于新手保护期（阶段一~二）？→ 是 → 跳过所有转型判定
    │
    ├── 是否触发主动转型判定？
    │   ├── 普通国：女性公民比例≥55%持续36回合？→ 是 → 凤鸣觉醒事件
    │   ├── 母系国：男性比例≤15%持续36回合？→ 是 → 女儿当国事件
    │   └── 否 → 继续监测
    │
    ├── 是否触发强制同化自身调整？
    │   ├── 已选择强制同化且未完成自身调整？→ 是 → 检查转型条件
    │   └── 否 → 跳过
    │
    └── 是否触发叛乱转型？
        ├── 性别比例失衡？→ 是 → 男权反扑叛乱判定
        ├── 外国渗透持续？→ 是 → 渗透叛变判定
        └── 否 → 继续监测
```
