## 四、普通国家奴隶购买与使用规则

> **核心规则**：普通国购买男奴/女奴**只能填充人口/劳力**，不能立即消耗（男奴繁殖）。奴隶购买后有**1回合消化期**，然后投入生产。

| 维度 | 规则 |
|------|------|
| **购买渠道** | 斯基泰女武奴市/阿玛宗女武奴市/各国奴隶市场 |
| **男奴用途** | 仅填充人口/劳力（矿工/农民/建筑工），不可立即消耗 |
| **女奴用途** | 填充人口/劳力（纺织/采药/家务），不可立即消耗 |
| **消化期** | 购买后1回合消化期→正式参与人口计算和生产 |
| **价格** | 50~150金/人（含距离浮动+市场浮动） |
| **叛乱风险** | 男奴比例>30%→叛乱风险+5%/月；需驻军监控 |
